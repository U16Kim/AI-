# Codex用 指示書 v2：note タイトル画像の「背景」2枚（文字なし）

PC側の Claude Code（Codex を呼べるセッション）に、この指示書をそのまま渡す。エージェントに依存しない書き方にしてある。

## 0. 分担と理由
- **Codex がやること**：絵の部分（背景）だけを、2案ぶん生成する。**画面内に文字・数字・ロゴ・人物を入れない**（日本語の文字が崩れるため）。
- **こちら（クラウドのセッション）がやること**：できた背景に、題名と副題の文字、バッジ、強調の矢印を重ねて、1280×670 のタイトル画像に仕上げる。文字は日本語の極太フォント（Noto Sans CJK JP Black）で、一字も崩さず入れる。
- 「22%の輪」（案3）は、割合の正確さが大事なデータ図なので、画像生成には出さない。こちらで正確に描く。

## 1. 出力
- 2枚のPNG。Codex の標準サイズ（1536×1024、3:2）でよい。後で中央を 1280×670 の比率に切り抜く。
- 保存先：`note_31/codex_bg/` に、次の名前で保存する。リポジトリが手元にない場合は、任意の場所に保存し、そのファイルをチャットに添付してよい。
  - `bg1_用途地域図.png`
  - `bg2_夜の街と窓のない箱.png`
- 回答に、保存した画像の絶対パスを書く。

## 2. 構図の共通ルール（切り抜きと文字のため）
- 重要な要素は、画面の縦の中央80%の帯（上下10%ずつは切れてよい）に収める。
- 左上（幅の60%、高さの45%）は、文字を載せるので、細部の少ない、落ち着いた場所にする。
- 文字、数字、記号、ロゴ、実在の会社名、人物は描かない。

## 4. 守ること
- 外部への送信内容は、この指示書の依頼文だけ。個人名・所属名・メールアドレス・未公表の情報は含まれていない。
- 生成後は、拡大して目で確認する。文字のようなものが写り込んでいる、窓がある（「窓のない箱」の指定違反）、左上が混んでいる、のいずれかなら、その画像は不採用にして、1回だけ作り直す。
- 報告は、1枚ごとに1行（採用／不採用、理由、絶対パス）。
