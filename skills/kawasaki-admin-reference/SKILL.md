# 川崎市 行政実務の確認済み事実集（確認日 2026-11-14。契約規則は 2026-11-15）

川崎市の公式サイトの公表資料で確認できた事実だけを集めた参照集。課長業務の各スキル（予算・契約、例規・補助金、議会・幹部、広報、人事・危機対応、プロジェクト運営）は、川崎市固有の事実が要るときにここを引く。

## 使い方と注意

- 事実を引くときは、出典URLと「確認日 2026-11-14」を添える。年度・組織・要綱は変わる。使う前にURLで再確認する。確認日から3か月を過ぎたものも同様。
- 凡例: ◎＝文書の本文で確認 / ○＝サイト・報道発表の本文で確認 / △＝一部のみ確認
- 資料の読み取りには、文書の抽出・要約を使った。**条文番号・数値は、公文書や答弁に引用する前に、必ず原文で再確認する**（読み違い・転記ミスの可能性がある）。
- 個人名（担当者名）は書かない。
- 共創推進室は令和8年4月からの組織（事務分掌規則の改正）。古い資料には旧組織名（例: シティプロモーション推進室）が残る。
- ここに無い事項は「未確認」。末尾の未確認リストを見て、推測で埋めない。
- 国の法令・判例は `japan-law-research`、東京都・横浜市の制度と3都市比較は `metro-gov-reference`、都市・建築・PPPの制度は `urban-development-practice` を使う。
- **更新のしかた**: 新しく確認できた事実は、該当の節の表に「事項・内容・確認の印」を1行、直下にURLを1行足す。未確認リストから消し、冒頭の確認日を直す。確認できなかった場合は、未確認リストに確認先と一緒に残す。
