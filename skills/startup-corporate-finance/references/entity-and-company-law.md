# 法人の選択と会社法の要点

金額・要件は目安（覚え書き）。法務省・法務局・日本公証人連合会・国税庁の案内で、現行の内容を確認する。登記は司法書士、税務は税理士に確認する。

## 1. 法人格の比較

| 観点 | 個人事業 | 合同会社（LLC） | 株式会社 | 一般社団法人 | NPO法人 |
|---|---|---|---|---|---|
| 設立の手間 | 開業届のみ | 定款（認証不要）、登記 | 定款認証、登記 | 定款認証、登記。社員2名以上 | 所轄庁の認証（数か月）。社員10名以上 |
| 設立費用の目安 | ほぼ0 | 登録免許税（最低6万円） | 定款認証手数料＋登録免許税（最低15万円） | 定款認証手数料＋登録免許税（6万円） | 登録免許税なし |
| 責任 | 無限 | 有限 | 有限 | 有限 | 有限 |
| 意思決定 | 本人 | 社員（出資者）の合意。定款で柔軟に設計 | 株主総会・取締役 | 社員総会・理事 | 社員総会・理事 |
| 利益の分配 | 本人 | できる（定款で自由に配分） | 配当できる | できない | できない |
| 資金調達 | 借入 | 借入が中心。出資の受入れは設計が難しい | 株式での調達がしやすい | 借入、会費、寄附、基金 | 寄附、助成金、会費 |
| 対外的な信用 | 低め | 中 | 高め | 中（公益性の印象） | 公益性の印象が強い |
| 決算公告・役員任期 | — | なし | 公告義務あり。任期あり（非公開会社は定款で最長10年） | 公告義務あり。任期あり | 事業報告の提出・公開 |
| 自治体からの受託 | 入札参加資格は取れるが、与信で不利な場面がある | 可 | 可 | 可。まちづくり団体・推進法人の器としても使われる | 可 |

**選び方の目安**：1人で始め、受託・顧問・研修が中心なら、合同会社か株式会社。外部から出資を受ける、将来の事業承継・売却を考えるなら株式会社。会員制の研究会・エリアマネジメント・非営利の活動が中心なら一般社団法人。複数の器を使い分ける（営利は会社、公益的な活動は社団）構成もある。

税務上の「非営利型」の一般社団法人の要件、公益認定は別の制度。

## 2. 株式会社の設立の流れ

1. 基本事項の決定：商号、目的、本店、資本金、発起人、機関設計、事業年度、公告方法。
2. 定款の作成（電子定款なら印紙税が不要）。
3. 公証人による定款認証。実質的支配者の申告。
4. 出資の払込み。
5. 設立登記の申請（会社の成立日は申請日）。
6. 設立後の届出：税務署（法人設立届、青色申告の承認申請、給与支払事務所の開設、源泉所得税の納期の特例）、都道府県・市、年金事務所（社会保険。役員1人でも加入）、労働基準監督署・公共職業安定所（従業員を雇う場合）。
7. 口座開設、インボイスの登録、入札参加資格の申請。

確認事項：代表者の住所を登記簿で非表示にする措置、オンライン・ワンストップの設立手続、市区町村の「特定創業支援等事業」を受けた場合の登録免許税の軽減。

## 3. 定款で決めること（株式会社・1人会社の例）

| 項目 | 考え方 |
|---|---|
| 目的 | 行う予定の事業を、許認可と入札参加資格の業種に合う言葉で書く（調査・研究、コンサルティング、ソフトウェア、研修、出版、建築設計を行うなら建築士事務所登録の要件も確認） |
| 株式の譲渡制限 | 置く（非公開会社）。知らない株主が入るのを防ぐ |
| 機関 | 取締役1名、取締役会・監査役は置かない形から始められる |
| 役員の任期 | 非公開会社は最長10年まで延ばせる。長すぎると、解任時の損害賠償の問題が出る |
| 事業年度 | 繁忙期と決算作業が重ならない月。自治体向けは3月が繁忙 |
| 資本金 | 1円でも設立できるが、信用、許認可、入札の格付け、税（資本金1,000万円以上は設立初年度から消費税の課税事業者）を考えて決める |
| 相続人等への売渡請求、株主総会の決議方法 | 将来、共同経営者が入る前に整える |

## 4. 会社法の要点

| 論点 | 条（覚え書き） | 要点 |
|---|---|---|
| 取締役の義務 | 330条（民法644条）・355条 | 善管注意義務、忠実義務。経営判断は、情報収集と判断過程が合理的なら尊重される（経営判断の原則） |
| 競業・利益相反 | 356条・365条 | 会社と取締役の取引、競業は、承認が要る |
| 役員の責任 | 423条・429条 | 会社に対する責任、第三者に対する責任（悪意・重過失） |
| 株主総会の決議 | 309条 | 普通決議（過半数）、特別決議（3分の2以上）。定款変更、合併、解散などは特別決議 |
| 株式・種類株式 | 107条・108条 | 譲渡制限、議決権制限、拒否権、取得条項など |
| 募集株式の発行 | 199条〜 | 非公開会社は、原則として株主総会の特別決議 |
| 新株予約権 | 236条〜 | ストックオプション。税制適格の要件は租税特別措置法 |
| 剰余金の配当 | 453条・461条 | 分配可能額の範囲内 |
| 計算書類・公告 | 435条・440条 | 貸借対照表の公告義務 |
| 持分会社（合同会社） | 575条〜 | 定款自治の範囲が広い。業務執行社員、利益配分、退社と持分の払戻し |
| 組織再編・事業譲渡 | 467条・748条〜 | 将来の合併・売却 |

共同創業・出資を受ける場合は、**株主間契約・創業者間契約**（役割、持株比率、退任時の株式の扱い、意思決定、競業の禁止）を、関係が良いうちに結ぶ。持株比率は、3分の2（特別決議を単独で通せる）、過半数、3分の1（特別決議を止められる）が節目。

## 5. 事業に関わるその他の法律

| 法律 | 関わる場面 |
|---|---|
| 民法（契約、請負・準委任） | 受託契約。成果物の完成を約束するか（請負）、業務の遂行を約束するか（準委任）で、責任が違う |
| 著作権法、不正競争防止法 | 報告書・分析モデル・コードの権利帰属、営業秘密、限定提供データ |
| 個人情報保護法 | 受託で個人データを扱う場合の安全管理、再委託、越境移転 |
| 中小受託取引適正化法、フリーランス・事業者間取引適正化等法 | 自分が受注者・発注者になる場合の、書面交付、支払期日、禁止行為 |
| 建築士法、建設コンサルタント登録、技術士法 | 設計・監理を業として行う場合の事務所登録、名称の表示 |
| 金融商品取引法、不動産特定共同事業法 | 出資を募る事業、不動産の小口化を行う場合（登録・届出が要る） |
| 労働基準法、労働契約法、社会保険各法 | 人を雇う場合 |
| 景品表示法、特定商取引法 | 広告、オンラインでの販売（有料記事、講座） |
| 入札参加資格の規程 | 自治体ごとの申請時期、実績・技術者数の要件 |
