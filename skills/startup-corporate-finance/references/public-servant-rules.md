# 公務員の規律と起業準備

条番号と内容は覚え書き。**必ず、地方公務員法の現行条文、川崎市の条例・規則（職員の営利企業への従事等の許可、退職管理）、人事担当課の運用で確認する。** 解釈が分かれる点は、自分で判断せず、人事担当課に事前に相談し、回答を記録に残す。

## 1. 在職中

| 規律 | 根拠（地方公務員法） | 起業準備との関係 |
|---|---|---|
| 営利企業への従事等の制限 | 38条 | 任命権者の許可なく、①営利企業等の役員等を兼ねる、②自ら営利企業を営む、③報酬を得て事業・事務に従事する、ことはできない。**会社の設立・役員就任、個人事業の開業は、許可の対象** |
| 職務専念義務 | 35条 | 勤務時間中に準備をしない。職場の機器・回線・メールを使わない |
| 守秘義務 | 34条 | 職務上知り得た秘密を、事業計画・営業資料・発信に使わない。退職後も続く |
| 信用失墜行為の禁止 | 33条 | 肩書を使った営業、職務と関連付けた宣伝をしない |
| 法令・上司の命令に従う義務 | 32条 | 内部の兼業・発信のルールに従う |
| 利害関係者との関係 | 各団体の倫理規程 | 将来の取引先・出資者になりうる相手から、便宜を受けない。職務上の関係者への勧誘をしない |

### 在職中にできること・確認が要ること（見立て）

| 行為 | 見立て | 確認先 |
|---|---|---|
| 学習、資格取得、事業計画の作成、市場調査（公開情報による） | できる（勤務時間外、私物で） | — |
| 無報酬の発信（ブログ、SNS、勉強会での発表） | 一般にできる。職務上の秘密、所属の見解との誤認、政治的行為に注意 | 所属の発信ルール |
| 有料記事、原稿料、講演料、書籍の印税 | 許可・届出の要否は団体の基準による。継続的・反復的な収入は「事業」と見られうる | 人事担当課 |
| 大学の非常勤講師、学会・審議会の委員 | 許可・届出の対象になることが多い | 人事担当課 |
| 会社の設立（発起人・出資のみ） | 出資だけなら直ちに禁止されないとの整理が一般的だが、実質的に経営に関わると「自ら営む」に当たりうる | 人事担当課 |
| 会社の役員就任、個人事業の開業届、屋号での受注 | 許可が要る | 人事担当課 |
| 家族名義の会社に関わる | 実質で判断される。名義を変えても、経営に関われば対象になりうる | 人事担当課 |
| 将来の顧客（自治体・企業）への営業、見積り、契約 | 事業の開始に当たる。職務上の関係者には特に行わない | — |

「見立て」は一般的な整理であり、川崎市の基準と異なる可能性がある。許可基準は、職務遂行への支障、利害関係、信用への影響の3点で判断されることが多い。

## 2. 退職後

| 規律 | 根拠（地方公務員法） | 内容（覚え書き） |
|---|---|---|
| 守秘義務 | 34条 | 退職後も続く。違反は罰則 |
| 元の職場への働きかけの規制 | 38条の2 | 営利企業等の地位に就いた元職員は、離職後2年間、離職前5年間に在職していた組織の職員に対し、その団体と自分の会社との契約等の事務で、離職前5年間の職務に属するものについて、職務上の行為をするよう（しないよう）要求・依頼してはならない |
| 幹部職員の上乗せ | 同条 | 局長級など一定の職にあった者は、離職前5年より前の、その職にあった期間の職務も対象 |
| 自ら決定した契約・処分 | 同条 | 在職中に自分が決定した契約・処分については、期間の制限なく、働きかけが禁止される |
| 条例による上乗せ | 同条 | 条例で、部課長級相当の職にあった者について、対象を広げることができる。**川崎市の条例の定めを必ず確認する（課長級は対象になりうる）** |
| 再就職の届出 | 38条の6と条例 | 退職後の一定期間、再就職先の届出を求める団体がある |
| 罰則・過料 | 60条・64条ほか | 不正な行為をするよう働きかけた場合は刑事罰、それ以外の違反は過料 |

### 事業モデルへの影響（最重要）

- 規制の対象は「働きかけ（要求・依頼）」。**一般競争入札や公募の手続に従って応募することなど、法律が定める適用除外がある**（条文の各号で確認）。元の職場と一切取引できない、という意味ではない。
- ただし、**随意契約の依頼、仕様への意見、公募前の情報提供の求め、担当者への個別の営業**は、働きかけに当たりうる。離職後2年間（対象職務によってはそれ以上）、元の職場の関係部署には、公開の手続以外で接触しない設計にする。
- 「自分の会社を自分で起こした」場合も、営利企業等の地位に就いた者として対象になる。個人事業主の扱いは、条文と解釈を確認する。
- 守秘義務により、在職中に知った未公表の計画・予算・事業者情報を、提案や営業に使えない。
- 公平性の観点から、元の職場が発注者となる案件では、形式上は適法でも、選定の公正さに疑いを持たれやすい。**最初の2〜3年は、川崎市以外の自治体・民間・国の案件で実績を作る計画**が現実的。

### 退職前に整理しておくこと

1. 離職前5年間の職務の一覧（所属、担当事務、自分が決裁・決定した契約・処分）。規制の範囲を自分で把握するため。
2. 持ち出してはいけないもの（庁内資料、名簿、未公表情報）と、使えるもの（公表資料、自分の一般的な知識・技能）の線引き。
3. 人事担当課への確認事項と回答の記録。
4. 取引先・協力者との関係の整理（在職中の利害関係者かどうか）。

## 3. 国内外の動き（視野を広げるために）

- 公務員の兼業・副業は、地域貢献や公益的な活動について、許可基準を明確にする自治体が増えている（国の通知、各市の基準）。営利事業の経営そのものを広く認めるものではない。
- 「回転ドア」（官民の人材の往来）への規制は、各国とも、冷却期間・働きかけの禁止・情報開示の組合せで行っている。日本の規制は、再就職そのものではなく行為（働きかけ）を縛る型。
- 任期付職員、官民人事交流、退職後の再任用・アドバイザーなど、「完全に辞める」以外の関わり方もある。
