## 1. 収支計画（1人で始めるコンサルティング事業の例）

```python
# 誰が：起業を検討する本人が／どのアプリで：JupyterLab か Google Colab で
# 何を：受託件数と単価の前提を／どうする：3通りの見通しで、手元資金の推移を見る
import pandas as pd

def plan(months, unit_price, deals_per_year, fixed_monthly, owner_pay, lag_months, cash0):
    """unit_price:1件の受注額 deals_per_year:年間受注件数 fixed_monthly:月の固定費
    owner_pay:月の役員報酬 lag_months:受注から入金までの月数 cash0:開始時の手元資金"""
    monthly_sales = unit_price * deals_per_year / 12
    cash, rows = cash0, []
    for m in range(1, months + 1):
        inflow = monthly_sales if m > lag_months else 0      # 入金は遅れて始まる
        cash += inflow - fixed_monthly - owner_pay
        rows.append({"月": m, "入金": inflow, "手元資金": round(cash)})
    return pd.DataFrame(rows)

cases = {"悲観": (300, 3), "標準": (400, 6), "楽観": (500, 9)}      # (単価 万円, 年間件数)
for name, (price, n) in cases.items():
    df = plan(24, price, n, fixed_monthly=25, owner_pay=50, lag_months=8, cash0=800)
    low = df["手元資金"].min()
    print(f"{name}: 資金の底 {low}万円（{df.loc[df['手元資金'].idxmin(), '月']}か月目）"
          f"／24か月後 {df['手元資金'].iloc[-1]}万円")
```

コードの意味：毎月の入金から、固定費と自分の報酬を引き、手元資金の残りを積み上げる。`lag_months` は「受注してから入金されるまでの遅れ」で、自治体の受託は年度末払いが多いため、長めに置く。3通りの前提で、資金が最も減る時点と額、2年後の残りを出す。この例では、入金が始まるまでの8か月で資金が最も減り、その深さは受注の多少では変わらない（**最初の資金繰りを決めるのは、売上の大きさより、入金までの遅れ**）。悲観の場合は、2年たっても資金が回復しない。**資金の底がマイナスなら、その額が必要な資金調達額の目安**になる。数値は例示。

見落としやすい費用：社会保険料の会社負担分、税理士・司法書士の報酬、賠償責任保険、ソフトウェア・データの利用料、入札保証・契約保証、消費税の納付、自分の住民税（前年所得に対して課税されるため、退職翌年が重い）。

## 2. 資金調達の選択肢

| 手段 | 向く場面 | 注意 |
|---|---|---|
| 自己資金 | 小さく始める | 生活費の蓄えと分ける。退職手当に頼りすぎない |
| 創業融資（日本政策金融公庫、自治体の制度融資＋信用保証協会） | 運転資金、設備 | 事業計画と自己資金の割合が見られる。経営者保証を求めない保証制度がある。制度名・要件は最新を確認 |
| 補助金・助成金 | 設備、販路、研究開発、創業 | 後払いが原則。採択されても入金は事業完了後。事務負担が大きい。補助金ありきの計画にしない |
| エクイティ（エンジェル、ベンチャーキャピタル、事業会社） | 急成長を狙うプロダクト型 | 持株比率の希薄化、出口（上場・売却）への期待。受託型の事業には合わないことが多い。投資家側の税優遇（エンジェル税制）がある |
| 新株予約権型の調達（J-KISSなど） | 創業初期の評価額を決めにくい段階 | 転換条件を理解する |
| クラウドファンディング、会員制、前受け | 実績づくり、共感型の事業 | 対価の設計、資金決済・金融規制の確認 |
| 受託の前払金・中間払 | 自治体・企業からの受託 | 契約で定める。自治体は前金払の要件が限られる |

## 3. 決算書の読み方

| 書類 | 分かること | 最初に見る所 |
|---|---|---|
| 貸借対照表（B/S） | ある時点の財産と借金 | 純資産はプラスか。現金と短期の借入のバランス |
| 損益計算書（P/L） | 1年間のもうけ | 売上総利益、営業利益。利益が出ていても現金が足りないことがある |
| キャッシュフロー計算書 | 現金の出入り | 営業活動による現金の増減 |

| 指標 | 式 | 見方 |
|---|---|---|
| 自己資本比率 | 純資産 ÷ 総資産 | 借金への依存の度合い |
| 流動比率 | 流動資産 ÷ 流動負債 | 短期の支払能力 |
| 営業利益率 | 営業利益 ÷ 売上高 | 本業のもうけやすさ |
| ROE・ROA | 利益 ÷ 自己資本／総資産 | 資本・資産の効率 |
| 労働分配率、1人あたり付加価値 | — | 人が資本の事業（コンサルティング）の要 |
| 損益分岐点売上高 | 固定費 ÷（1 − 変動費率） | いくら売れば赤字にならないか |

官民連携の相手方の与信、指定管理者・PFI事業者の財務の確認にも、同じ見方を使う。自治体の財務（健全化判断比率、財政力指数、経常収支比率、基金と地方債の残高）は別の体系。

## 4. 税・社会保険の論点（項目のみ。税率・期限は国税庁等で確認）

- 法人：法人税・地方法人税・法人住民税（赤字でも均等割がかかる）・法人事業税。中小法人の軽減税率は期限付きの特例。
- 消費税：課税事業者になる時期（基準期間の売上、資本金、特定期間）、インボイスの登録、簡易課税の選択。自治体・企業との取引では、インボイスの登録を求められることが多い。
- 役員報酬：定期同額でないと、損金にできない部分が出る。期首から3か月以内に決める。
- 個人：給与所得と事業所得、青色申告、退職所得の課税、住民税、国民健康保険か任意継続か、年金の種別の切替え。公務員は雇用保険の対象外であり、失業給付はない。
- 帳簿：複式簿記、電子帳簿保存法（電子取引データの保存）、証憑の保存期間。
- 法人成りの時期：所得が増えると法人が有利になるが、社会保険料・維持費を含めて試算する。

## 6. 金融・経済環境の読み方

現在の水準（政策金利、長期金利、為替、物価）は、日本銀行・財務省・総務省統計局の公表値で必ず確認する。ここでは、読み方の枠組みだけを示す。

| 見るもの | 読み方 | 事業・政策への効き方 |
|---|---|---|
| 政策金利・短期金利 | 中央銀行が直接動かす。物価と景気の見通しで決まる | 変動金利の借入、預金、企業の資金繰り |
| 長期金利（10年国債利回り） | 将来の短期金利の予想＋上乗せ（期間の危険への対価） | 地方債・固定金利の借入の費用、PFIの資金調達コスト、VFMの前提、不動産の利回り |
| 利回り曲線 | 短期と長期の金利の差。逆転は景気後退の先触れとされることが多い | 景気の見通し |
| 為替 | 内外の金利差、物価、経常収支、リスクへの姿勢 | 輸入物価、建設資材・エネルギー価格、訪日消費 |
| 物価（消費者物価、企業物価、建設工事費デフレーター） | 需要と供給、賃金、輸入価格 | 工事費、指定管理料・委託料の改定、実質の予算規模 |
| 賃金・雇用 | 人手不足の度合い | 入札不調、委託の担い手、採用 |
| 株価・信用スプレッド | 企業収益の見通しと、危険への対価 | 民間の投資意欲、開発事業者の資金調達 |
| 不動産（地価、賃料、空室率、取引利回り） | 利回り ≒ 安全資産の金利＋上乗せ。金利が上がれば、価格に下げの力が働く | 再開発の成立性、公有地の処分価格、固定資産税収 |
| 地方財政 | 税収、地方交付税、地方債、基金 | 予算編成の環境、投資的経費 |
