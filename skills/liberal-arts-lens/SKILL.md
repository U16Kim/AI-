# 教養の視座（地政学・経済学・社会学・哲学）

実務の議論は、目の前の制度と数字に閉じやすい。このスキルの目的は、**理論を「飾り」ではなく「道具」として使い、①見えていない前提を掘り出し、②反対の立場からの最も強い議論を立て、③実務の選択肢を増やすこと**。

## 使い方

1. **問いを1文にする。** 「この政策は良いか」ではなく、「誰の、何を、何と引き換えに良くするのか」。
2. **レンズを2〜3枚選ぶ**（下の表。必ず、互いに違う結論を出しそうなものを組み合わせる）。
3. **各レンズで読む**：そのレンズは何を見せ、何を見えなくするか。参照ファイルの「問い」を当てる。
4. **ぶつける**：レンズ同士が食い違う点を明示する。食い違いこそが、判断の本当の論点。
5. **実務に戻す**：選択肢、設計の修正、説明の言葉、測るべき指標に落とす。理論の紹介で終わらせない。

## 共通ルール

- 最初に「概略」を簡単な日本語で、次に詳細を書く。学術用語は、使うたびに普通の言葉で言い換える。
- **理論家の名前・著作・発表年・主張の内容は、確かなものだけを書く。** 引用文は、原典で確認できたものに限る。あいまいなら、名前を出さずに考え方だけを説明する。
- 理論は「この現実を説明する有力な見方の一つ」として示す。断定しない。理論への主な批判を1つ添える。
- 時事（国際情勢、経済指標、選挙、紛争）は、必ず最新の一次情報・信頼できる報道で確認し、日付を書く。記憶の情勢を現在のものとして語らない。
- 政治的に意見が分かれる論点は、主要な立場を公平に並べる。
- 客観的な整理の後に、ユーザーの立場（自治体の官民共創の責任者、将来の起業）に引きつけた見解を、分けて書く。
- 最後に、**発想を広げる問い・キーワード・読むべき原典**を3つ程度示す。

## 出力の型

```
概略（3行）
1. 問いの言い直し
2. レンズA で読む（見えること／見えなくなること）
3. レンズB で読む（同上）
4. 食い違いと、本当の論点
5. 実務への示唆（選択肢・設計・説明・指標）
6. 反対の立場からの最も強い議論
7. 次に考える問い・キーワード・原典
出典
```

## よく使う場面

| 場面 | 組み合わせの例 |
|---|---|
| 官民共創の正当性を説明する | 市場の失敗 × 公共性・熟議 × 権力（誰が得をするか） |
| 公共空間の民間活用への批判に答える | コモンズ × 都市への権利 × 契約理論 |
| スマートシティ・データ活用の是非 | 情報の非対称性 × 監視とプライバシー × 知識と不確実性 |
| 人口減少下の縮退・再編 | 足による投票 × 正義論（世代間・地域間）× 社会関係資本 |
| 補助金・誘致策の評価 | 誘因 × 政府の失敗 × 都市の経済学 |
| 物価・金利・資材高の背景 | 地政学 × 国際経済 × 自治体財政 |
| 起業の事業構想 | 取引費用 × 弱い紐帯 × 知識の分散 |
