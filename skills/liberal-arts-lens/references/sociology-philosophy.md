# 社会学・哲学のレンズ

理論家・著作・年は覚え書き。記事・資料に書く前に、原典や信頼できる事典で確認する。引用文は、原典で確認できたものだけを使う。

## A. 社会学

### 1. つながりとコミュニティ

| 概念 | 要点 | 実務で当てる問い |
|---|---|---|
| ゲマインシャフトとゲゼルシャフト（テンニース） | 地縁・血縁の共同体と、利害で結ぶ社会 | 「地域コミュニティの再生」は、どちらを目指しているのか |
| アノミー、連帯の型（デュルケーム） | 規範が弱まると、人は拠り所を失う。似た者同士の連帯と、分業による連帯 | 都市の孤立への対策は、何を拠り所として作るのか |
| 社会関係資本（パットナム、コールマン、ブルデュー） | 信頼・規範・ネットワークは、協力を生む資源。仲間内を固める型と、外へ橋を架ける型 | 施策は、既存の団体を強めるだけか、新しい層に橋を架けるか |
| 弱い紐帯の強さ（グラノヴェッター） | 新しい情報や機会は、親しい相手より、薄い知り合いから届く | 官民共創の場は、普段会わない人同士を出会わせているか |
| サードプレイス（オルデンバーグ） | 家庭でも職場でもない、気軽に集える場 | 公共空間は、用がなくても居られる場になっているか |
| 社会的インフラ（クリネンバーグ） | 図書館・公園・広場などが、人のつながりと災害時の助け合いを支える | 施設の再編で、つながりの場を減らしていないか |
| コモンズ（オストロム）、社会的共通資本（宇沢弘文） | 共有の資源を、利用者の規則で持続的に管理できる条件 | エリアマネジメントは、誰が規則を決め、守らせ、費用を負うか |

### 2. 権力・格差・排除

| 概念 | 要点 | 実務で当てる問い |
|---|---|---|
| 官僚制、支配の三類型（ウェーバー） | 規則による支配は、公平と予測可能性をもたらすが、硬直も生む | 規則の柔軟化は、公平と予測可能性をどこまで削るか |
| 現場の裁量（リプスキー） | 窓口の職員の判断が、事実上の政策になる | 制度は、現場でどう運用されているか |
| 文化資本・ハビトゥス（ブルデュー） | 育ちで身に付く振る舞いが、有利・不利を再生産する | 参加の場は、慣れた人だけのものになっていないか |
| 参加の梯子（アーンスタイン） | 形だけの参加から、実質的な権限の共有まで、段階がある | この「市民参加」は、梯子のどの段か |
| 規律・統治（フーコー） | 権力は、禁止だけでなく、測り、分類し、望ましい振る舞いへ導く形でも働く | データによる最適化は、誰の「望ましさ」を埋め込んでいるか |
| 監視資本主義（ズボフ） | 行動データが、予測と誘導の商品になる | スマートシティのデータは、誰のもので、誰が利益を得るか |
| 意図せざる結果、予言の自己成就（マートン） | 目的を持った行為は、予期しない結果を生む | この施策が成功した場合の副作用は何か |

### 3. 都市の社会理論

| 概念 | 要点 | 実務で当てる問い |
|---|---|---|
| 大都市と精神生活（ジンメル）、アーバニズム（ワース） | 規模・密度・異質性が、都市に特有の関わり方を生む | 匿名性は、欠点か、自由の条件か |
| シカゴ学派（パーク、バージェス） | 都市を、集団の住み分けと移り変わりとして見る | 地区の変化は、誰の流入・流出で起きているか |
| 街路の多様性（ジェイコブズ） | 用途の混在、短い街区、古い建物、密度が、にぎわいと安全を生む | 再開発は、この4条件を壊していないか |
| 空間の生産、都市への権利（ルフェーブル）、ハーヴェイ | 都市空間は、資本と権力の関係で作られる。住民には、都市を使い、作り変える権利がある | 公共空間の民間活用は、誰の利用を広げ、誰の利用を狭めるか |
| ジェントリフィケーション | 地区の高級化により、元の住民・店が押し出される | にぎわいの成功は、家賃と立ち退きに何をもたらすか |
| グローバル・シティ（サッセン） | 世界経済の指令機能が集まる都市では、高所得層と低賃金のサービス労働に分かれる | 国際競争力の強化は、市内の格差をどう変えるか |
| 創造階級（フロリダ） | 創造的な人材が、都市の成長を引っ張るという見方。格差を広げたとの批判と、本人による見直しがある | 人材誘致策は、既に住む人に何をもたらすか |
| リスク社会（ベック） | 近代化が生んだ危険は、見えにくく、広く及び、専門家でも見解が割れる | 災害・環境・技術のリスクを、誰が、どう決めるのか |
| 国家の視点（スコット） | 行政は、社会を「読みやすく」単純化して把握する。現場の知恵を無視した大規模な計画は、失敗しやすい | 計画・データが切り捨てている、現場の実践知は何か |

日本の文脈：柳田國男・宮本常一の民俗学（暮らしと地域の記憶）、都市社会学のコミュニティ論、広井良典の定常型社会・コミュニティ論、和辻哲郎の風土論。町内会・自治会、講、祭礼など、地域に固有の結び付きを、理論の輸入だけで語らない。

## B. 哲学・倫理学

### 1. 何をもって「良い」とするか

| 立場 | 要点 | 政策への当て方 | 主な批判 |
|---|---|---|---|
| 功利主義（ベンサム、ミル） | 幸福の総量を最大にする | 費用便益分析の土台 | 少数者の犠牲を正当化しうる |
| 義務論（カント） | 人を、単なる手段として扱わない。普遍化できる原則に従う | 権利、手続の正しさ、同意 | 原則同士がぶつかるときに決められない |
| 正義論（ロールズ） | 自分の立場を知らない状態で選ぶ原理。基本的な自由の平等、機会の公正な平等、最も不利な人の利益になる格差だけを認める | 最も不利な人から見て、この施策はどうか | 何を「不利」と見るか。共同体の価値を軽く見る |
| 自由至上主義（ノージック） | 個人の権利と、同意のない再分配への批判 | 行政の関与の最小化 | 出発点の不平等を放置する |
| 共同体主義（サンデル、マッキンタイア、ウォルツァー） | 人は、共同体の物語と価値の中で生きる。財ごとに、ふさわしい配り方がある | 何でも市場に任せてよいか | 共同体の多数派の価値を押し付けうる |
| 潜在能力（セン、ヌスバウム） | 大切なのは、所得ではなく、実際に何ができ、何になれるか | 指標を、資源の量から、できることの広がりへ | 何を基本的な能力とするか |
| 徳倫理・実践知（アリストテレス） | 規則の当てはめではなく、状況に応じた賢い判断 | 管理職の判断、専門家の裁量 | 基準があいまい |
| 世代間倫理（ヨナス） | 将来世代への責任 | 長寿命のインフラ、環境、財政負担の先送り | 将来世代の利益を、誰が代弁するか |
| 危害原理、二つの自由（ミル、バーリン） | 他人に害を与えない限り、個人の自由に干渉しない。干渉されない自由と、自分で決める力としての自由 | 規制・ナッジ・見守りの正当化の限界 | 害の範囲の線引き |

### 2. 公共性と決め方

| 概念 | 要点 | 実務で当てる問い |
|---|---|---|
| 公共性の意味 | 「国・行政に関わる」「全ての人に共通する」「誰にでも開かれている」の3つの意味が混ざって使われる | この「公共性」は、どの意味か。行政がやること＝公共、としていないか |
| 活動と現れの空間（アーレント） | 人が、互いに違う者として現れ、語り、行為する場が、公共の領域 | 公共空間は、消費の場だけでなく、違う者同士が出会う場になっているか |
| 公共圏・熟議（ハーバーマス） | 理由を示し合う議論を通じて、正当性が生まれる | 決定の正当性は、結果の良さだけでなく、手続から来ているか |
| 公衆（デューイ） | 行為の影響を受ける人々が、問題を自分たちのものとして見いだすとき、公衆が生まれる | 影響を受ける人は、問題を知り、関われているか |
| 社会的選択の限界（アロー） | 個人の好みを、常に筋の通った形で集計する完全な方法はない | 「市民の意向」を1つに決める方法の限界を、説明できるか |

### 3. 知識と不確実性

| 概念 | 要点 | 実務で当てる問い |
|---|---|---|
| 反証可能性、漸進的な改良（ポパー） | 理論は、間違いを示せる形でなければならない。社会の全面的な設計ではなく、小さく試し、誤りから学ぶ | この計画は、何が起きたら「失敗」と認めるのか。小さく試せるか |
| 漸進主義（リンドブロム） | 現実の政策は、少しずつの修正で進む | 全面改定と、段階的な修正の、どちらが合うか |
| 厄介な問題（リッテル、ウェバー） | 都市・社会の問題は、定義自体が立場で違い、正解がなく、試し直しがきかない | 問題の定義を、関係者と共有したか |
| 政策の窓（キングダン） | 問題・政策案・政治の3つの流れが合ったとき、政策が動く | 今、窓は開いているか。開いたときに出せる案はあるか |
| 認識の限界 | 分かっていること、分からないと分かっていること、分からないことすら分からないこと | 計画に、想定外への備え（余裕、撤退基準、やり直しの余地）はあるか |

## C. レンズを使うときの注意

- 理論で相手を言い負かさない。理論は、論点を見つけるための道具。
- 西洋の理論を、日本の地域にそのまま当てない。制度・歴史・慣行の違いを確かめる。
- 批判理論（権力・排除）は、行政実務では「では、どう設計を変えるか」まで下ろす。批判だけで終えない。
- 規範の議論（べき）と、事実の議論（である）を分ける。事実はデータで確かめる（`data-science-foundations`）。
