# 経済学のレンズ

理論家・著作・年は覚え書き。記事・資料に書く前に、原典や信頼できる事典で確認する。

## 1. なぜ行政が関与するのか（市場の失敗）

| 概念 | 要点 | 実務で当てる問い |
|---|---|---|
| 公共財（サミュエルソン） | 対価を払わない人を排除できず、誰かが使っても減らない財は、市場では足りなくなる | この事業は本当に公共財か。料金を取れる部分（クラブ財）と分けられないか |
| 外部性（ピグー、コース） | 取引の外にいる人への良い影響・悪い影響。税・補助金で調整する考え方と、権利を定めて交渉に任せる考え方 | 便益は誰に及ぶか。受益者に負担を求める道はあるか（開発利益の還元、負担金） |
| 情報の非対称性（アカロフ） | 売り手と買い手の情報の差が、市場を壊す | 行政の役割は、供給か、情報の開示・認証か |
| 自然独占・ネットワーク | 規模が大きいほど安くなる事業は、独占になりやすい | 所有と運営を分けられるか（コンセッション）。料金と水準を誰が見張るか |
| 所得再分配・価値財 | 効率とは別の理由による関与 | 効率の議論と、公平の議論を混ぜていないか |
| 財政の3機能（マスグレイブ） | 資源配分、所得再分配、経済安定化 | 自治体が担うべき機能はどれか（再分配と安定化は、国が担う方が合うとされる） |

## 2. 関与は失敗しないか（政府の失敗）

| 概念 | 要点 | 実務で当てる問い |
|---|---|---|
| 公共選択論（ブキャナン、タロック） | 政治家・官僚・有権者も、自分の利益で動く | この制度は、誰の利益で維持されているか |
| 予算最大化（ニスカネン） | 官僚組織は予算の拡大を目指しやすい | 事業の廃止・縮小の仕組みはあるか |
| 集合行為論（オルソン） | 少数で利害の強い集団は組織化しやすく、多数で薄い利害は代表されにくい | 声の大きい関係者の後ろに、黙っている多数はいないか |
| レントシーキング | 規制・補助金による利益を求める活動に、資源が使われる | 補助金・規制緩和が、特定の事業者の利益になっていないか |
| グッドハートの法則、キャンベルの法則 | 指標を目標にすると、指標が歪む | KPIは、現場の行動をどう変えるか。数字合わせを招かないか |
| ルーカス批判 | 政策を変えると、人々の行動の前提も変わる | 過去のデータで推計した効果は、制度を変えた後も成り立つか |
| ボーモルのコスト病 | 人手に頼るサービスは、生産性が上がりにくく、相対的に高くなる | 福祉・教育・文化の費用増を、非効率と決めつけていないか |
| 知識の分散（ハイエク） | 必要な知識は、現場に散らばっていて、中央には集められない | 計画で決める範囲と、現場・市場に任せる範囲の線引きは妥当か |

## 3. 誘因と契約（官民連携の理論的な土台）

| 概念 | 要点 | 実務で当てる問い |
|---|---|---|
| 代理人問題（依頼人と代理人） | 任せた相手は、依頼人の利益どおりには動かない。監視と報酬設計が要る | 指定管理者・受託者の報酬は、望む行動に結び付いているか |
| 複数の任務（ホルムストローム、ミルグロム） | 測りやすい成果だけに報酬を付けると、測りにくい仕事が手抜きされる | 成果連動の指標が、質や公共性を削らないか |
| 不完備契約（ハート） | 将来の全てを契約に書けない。書けない部分は、所有者が決める。費用削減の動機が、質の低下を招くことがある | 質を契約で縛りにくい事業を、民間に任せていないか。所有を残す意味は何か |
| 取引費用（コース、ウィリアムソン） | 市場で買うか、組織の中で作るかは、取引の費用で決まる。特殊な投資が要る取引は、後で足元を見られやすい（ホールドアップ） | 長期契約で、片方が逃げられなくなる投資は何か。再交渉のルールはあるか |
| 逆選択・モラルハザード | 契約前の情報の差と、契約後の行動の変化 | 公募に、望ましくない事業者ばかりが集まる条件になっていないか |
| 離脱・発言・忠誠（ハーシュマン） | 不満への反応は、去るか、声を上げるか | 住民・利用者が、声を届ける経路はあるか |

## 4. 都市・空間の経済学

| 概念 | 要点 | 実務で当てる問い |
|---|---|---|
| 集積の経済（マーシャル、ジェイコブズ） | 同業の集まりによる利益と、多様性による利益 | この地区の強みは、専門化か、多様性か |
| 付け値地代（アロンゾ） | 都心への近さと地代が引き換えになり、土地利用が決まる | 交通の改善は、地価と土地利用をどう変えるか。誰が得をするか |
| 足による投票（ティブー）、分権化定理（オーツ） | 住民は、税とサービスの組合せで自治体を選ぶ。地域ごとの好みに合う供給は、分権の方が合う | 隣の市との競争で、何を競っているか。競争が底辺への競争にならないか |
| 開発利益と地価（ヘンリー・ジョージ） | 公共投資の便益は、地価に帰着する | 地価上昇分を、どう公共に戻すか（固定資産税、負担金、容積と公共貢献の交換） |
| 新経済地理（クルーグマン） | 輸送費と規模の経済で、集中と分散が決まる | 交通網の整備は、地方を強くするか、吸い上げるか |
| 都市の成長と住宅供給（グレイザー） | 規制で供給を絞ると、住宅費が上がり、人が入れなくなる | 規制の便益（環境・景観）と、住宅費への影響を比べたか |
| 混雑・共有資源（ハーディン、オストロム） | 誰でも使える資源は使われすぎる。ただし、利用者自身の規則で管理できる場合がある | 公共空間の管理は、行政・市場のほかに、利用者による自治という道がないか |

## 5. 行動経済学

| 概念 | 要点 | 実務で当てる問い |
|---|---|---|
| 限定合理性（サイモン） | 人は、十分に良い選択で手を打つ | 申請・手続は、迷わず終えられる設計か |
| プロスペクト理論（カーネマン、トベルスキー） | 損は、同じ額の得より重く感じる。基準点で評価が変わる | 伝え方（得を示すか、損を示すか）を試したか |
| 現状維持・初期設定の力 | 人は、最初の設定を変えない | 望ましい選択を、初期設定にできるか |
| 現在志向 | 目先を重く見る | 締切・小さな報酬・すぐ分かる反応を組み込めるか |
| ナッジ（セイラー、サンスティーン） | 選択の自由を残したまま、選びやすくする | 効果を測ったか。操作との線引き、透明性は保たれているか |

## 6. マクロ・国際経済の基本

- 景気と物価：需要と供給、期待、賃金。金融政策（金利）と財政政策（支出・税）の役割分担。
- 国際収支と為替：金利差、物価、経常収支。交易条件の悪化は、輸入に頼る資材・エネルギーの価格を通じて、自治体の事業費に届く。
- 人口と成長：労働力、資本、生産性。人口減少の下では、1人あたりで見る。
- 格差（ピケティ）：資本の収益率と成長率の関係という見方と、それへの批判。
- 自治体財政への伝わり方は `startup-corporate-finance` の `references/finance-and-accounting.md` 6節。

## 7. 経済学のレンズの限界

- 効率を測るのは得意だが、分配・権利・尊厳は、別の基準が要る（`sociology-philosophy.md`）。
- 前提（合理性、完全な情報、取引費用ゼロ）が現実に合うかを、常に確かめる。
- お金に直せない価値（歴史、景観、関係）を、無理に金額に直すと、議論が歪むことがある。
