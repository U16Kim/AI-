# 地政学・国際政治のレンズ

**情勢そのものは、ここに書かない。** 国際情勢は日々変わるため、現状は必ず、最新の一次情報（各国政府・国際機関の発表）と信頼できる報道で確認し、日付を書く。ここにあるのは、読み解くための枠組みと、自治体・事業への伝わり方。継続的な観測は `world-affairs-update` のノートを使う。

## 1. 読み解く枠組み

| 見方 | 要点 | 当てる問い |
|---|---|---|
| 古典地政学（マハン、マッキンダー、スパイクマン） | 海を制する力、大陸の内陸部、その縁の地帯。地理が、国の選択を縛る | 海上交通路、要衝、資源の位置は、当事国の行動をどう縛っているか |
| 現実主義（モーゲンソー、ウォルツ、ミアシャイマー） | 国家は、無政府の国際社会で、安全と力を求める。力の均衡 | 力の配分は、どう変わっているか。同盟はどう動くか |
| 自由主義・相互依存（コヘイン、ナイ） | 貿易・制度・国際機関が、協力を可能にする | 経済の結び付きは、対立を抑えているか、弱みになっているか |
| 構成主義（ウェント） | 利益や脅威の認識は、理念・規範・アイデンティティで形作られる | 当事者は、相手をどう認識しているか。物語は何か |
| 覇権の移り変わり | 台頭する国と、既存の大国の間の緊張 | 競争は、どの分野（軍事、技術、通貨、規範）で起きているか |
| 相互依存の武器化（ファレル、ニューマン） | 金融・通信・供給網の結節点を握る国が、それを圧力の手段に使う | 自国・自社は、どの結節点に依存しているか |
| ソフトパワー（ナイ） | 文化・価値・政策の魅力で、相手を動かす | 都市の魅力・国際発信は、何を目的にしているか |

1つの見方で決めつけず、少なくとも2つの見方で読み、食い違いを書く。

## 2. 定点で見る項目

| 区分 | 見るもの |
|---|---|
| 安全保障 | 主要国の国防・同盟の動き、紛争と停戦、海上交通の要衝（ホルムズ海峡、マラッカ海峡、スエズ運河・紅海、パナマ運河、台湾海峡など）の状況 |
| 経済安全保障 | 輸出管理、投資規制、関税、制裁、重要鉱物、半導体、エネルギー、食料 |
| 国際経済 | 主要国の金融政策、為替、資源価格、海上運賃、債務 |
| 技術 | AI・半導体・量子・宇宙・サイバーの規制と競争、データの越境移転のルール |
| 国際制度 | 国連、G7、G20、WTO、気候変動の枠組み、地域の経済連携 |
| 国内政治 | 主要国の選挙と政権、世論 |
| 気候・災害・感染症 | 異常気象、食料・水、移民、保健 |

情報源：外務省・防衛省・経済産業省の白書と公表資料、内閣官房（経済安全保障）、日本銀行、各国政府・中央銀行、国連・IMF・世界銀行・OECD・IEA・WTO、主要シンクタンクの報告。報道は複数を突き合わせ、一次情報にさかのぼる。

## 3. 自治体・都市・事業への伝わり方

| 経路 | 起きること | 影響を受ける実務 |
|---|---|---|
| エネルギー・資源価格 | 光熱費、燃料費、資材価格の上昇 | 施設の運営費、指定管理料、工事費、入札不調、スライド条項 |
| 為替・金利 | 輸入物価、借入の費用 | 予算の実質規模、地方債、PFIの資金調達、再開発の成立性 |
| 供給網の寸断 | 資材・機器の納期の遅れ | 工期、設備更新、災害備蓄 |
| 経済安全保障の規制 | 重要インフラの設備・委託先の審査、特定の機器・サービスの調達制限、土地利用の調査 | 情報システムの調達、上下水道・港湾などの基幹インフラ、重要施設周辺の土地 |
| 産業立地の変化 | 国内回帰、半導体・データセンター・蓄電池の投資、撤退 | 産業用地、電力・水、人材、臨海部の土地利用転換 |
| 人の移動 | 訪日客、外国人住民、高度人材、留学生、避難民 | 多文化共生、住宅、教育、観光、労働力 |
| 技術とルール | AI・データの規制、標準化、越境移転 | 生成AIの利用、スマートシティのデータ基盤、クラウドの選定 |
| 安全・危機管理 | サイバー攻撃、偽情報、国民保護 | 情報セキュリティ、広報、避難計画、港湾・空港の利用 |
| 都市間の関係 | 姉妹都市、都市外交、国際会議・博覧会 | 国際交流、誘致、発信 |

川崎市に引きつけて読むときの視点：臨海部のコンビナートとエネルギー転換（水素、カーボンニュートラル）、港湾と物流、研究開発拠点、外国人住民の多さ、羽田空港への近さ。事実は、市の公表資料で確認する（`kawasaki-admin-reference`）。

## 4. 関係する国内法（項目のみ。内容は条文で確認）

- 経済安全保障推進法（令和4年）：供給網の強靱化、基幹インフラの事前審査、先端技術の開発支援、特許出願の非公開。
- 重要経済安保情報の保護及び活用に関する法律（セキュリティ・クリアランス制度）。
- 重要土地等調査法：重要施設の周辺・国境離島の土地利用の調査と規制。
- 外国為替及び外国貿易法：対内直接投資の審査、輸出管理。
- 国民保護法、災害対策基本法、サイバーセキュリティ関係の法律。

## 5. 情勢を語るときの作法

1. 「いつ時点の情報か」を最初に書く。
2. 事実（何が起きたか）、解釈（なぜか）、見通し（どうなりうるか）を分ける。見通しは、複数の筋書きと、それぞれの兆候を示す。
3. 当事者それぞれの立場と論理を、公平に書く。
4. 「だから、川崎市・自分の事業にとって何か」を、経路（3の表）に沿って1つ以上示す。
5. 分からないことは、分からないと書く。
