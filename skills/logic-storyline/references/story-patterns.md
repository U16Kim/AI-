# ストーリーの型と、惹きつける技法

## 1. 場面別の構成の型

| 場面 | 型 | 並び |
|---|---|---|
| 決裁・了承を求める | 結論先行型 | Ask → 理由3つ → 選択肢の比較 → リスクと対応 → 財政影響 → 工程 → Ask |
| 方針を選んでもらう | 選択肢型 | 決めてほしいこと → 判断の基準 → 案の比較（やらない案を含む）→ 推奨と理由 → 選んだ後の進め方 |
| 新しい施策を提案する | 課題解決型 | 現状と、あるべき姿の差 → 原因 → 解決の方針 → 具体策 → 効果と費用 → 工程 → Ask |
| 反対・慎重な相手に説明する | 共通点先行型 | 相手と共有できる目的・懸念 → 事実 → 相手の懸念への答え → 提案（条件・段階付き）→ 相手に求めること |
| 経過・結果を報告する | 要点先行型 | 結論（順調／課題あり）→ 主な事実3点 → 原因 → 今後の対応 → 求める判断 |
| 悪い知らせを伝える | 事実先行型 | 何が起きたか → 影響 → 原因（分かっている範囲）→ 対応 → 再発防止 → 次の報告の時期。言い訳を先に置かない |
| ビジョン・講演 | 対比型 | 今の姿 → ありうる未来 → その間の壁 → 越える方法 → 聞き手への呼びかけ |
| 分析結果を伝える | 発見先行型 | 問い → 答え（主な発見）→ 根拠（図1〜3枚）→ 限界 → 政策への示唆 |
| 記事・論考 | 問い牽引型 | 読者の実感に触れる導入 → 問い → 通説 → データ・事例で通説を揺らす → 自分の見方 → 残る問い |
| 公募・提案書 | 評価基準対応型 | 要旨 → 評価項目の順に、要求→提案→根拠→実績を対応させる。審査員が採点表に写しやすい並び |
| 住民・地元への説明 | 生活起点型 | 暮らしの何が変わるか → なぜ必要か → いつ、どこで、何が起きるか → 困るときの相談先 → 意見の出し方 |

## 2. 惹きつける技法（行政・ビジネスの資料で使えるもの）

| 技法 | やり方 | 注意 |
|---|---|---|
| 具体の1場面から入る | 「昨年8月、〇〇公園でイベントを申請した団体は、3つの窓口を計7回訪ねた」 | 実在の事実に限る。作り話をしない |
| 数字を1つに絞る | 最も効く数字を、大きく、単独で見せる | 比べる相手（前年、他都市）を添える |
| 落差を見せる | あるべき姿と現状、他都市と本市、費用と効果 | 落差の原因まで示す |
| 問いで引っ張る | 節の冒頭に、読み手が気になる問いを置き、その節で答える | 答えない問いを置かない |
| 3つにまとめる | 根拠、施策の柱、次の一歩を3つに | 無理に3つにそろえない。本当は2つなら2つ |
| 対比で名付ける | 「待つ行政から、迎えに行く行政へ」のように、変化を一言で | 中身のない標語にしない。直後に具体を置く |
| 当事者の声 | 利用者・事業者の言葉を、短く引用する | 出典と同意。都合のよい声だけを選ばない |
| 図で一目に | 体系図、流れ図、比較表、路線図型の工程表 | 1枚1メッセージ。図の要素は9個以内 |
| 山場の前に間を置く | 山場の直前のページは、情報を減らす | 全ページを強くしない |
| 予想を裏切る事実 | 通説と違うデータを示す | データの確かさが命。弱いデータでやらない |
| 繰り返し | 鍵となる言葉・数字・期限を、同じ表現で3回（冒頭・山場・締め） | 言い換えない。言い換えると別の話に聞こえる |
| 相手の言葉で語る | 相手の計画・方針・過去の発言の言葉を使う | 文脈を曲げない |

## 3. 読み手別の調整

| 読み手 | 最初に知りたいこと | 効く材料 | 避けること |
|---|---|---|---|
| 市長・副市長 | 何を決めるのか。市民にどう説明できるか | 市民への効果、他都市との比較、期限 | 細部から入る。専門用語 |
| 局長・部長 | 自局の責任と負担。議会・財政への説明 | リスクと対応、庁内の調整状況、想定問答 | 関係課の合意が曖昧なまま出す |
| 財政担当 | 総額、後年度負担、財源、やめる条件 | 積算の根拠、費用対効果、他の手段との比較 | 効果の誇張、将来負担の過小評価 |
| 議員 | 地元・支持者への意味。過去の答弁との整合 | 具体の地区・人数、時期、公平性 | 約束できないことを言う |
| 民間企業の経営層 | 事業機会と条件。意思決定の速さ | 市場規模、役割分担、リスク分担、工程 | 行政用語、決定権限の不明確さ |
| 民間の担当者 | 何を、いつまでに、どう出せばよいか | 手続の流れ、様式、窓口、事例 | 抽象的な理念だけ |
| 住民・地元 | 自分の暮らしへの影響 | 地図、時期、相談先、意見の反映のされ方 | 上からの説明、専門用語、決定済みの印象 |
| 専門家・学識者 | 方法とデータの確かさ | 出典、手法、限界の明示 | 断定、根拠のない一般化 |
| 記事の読者 | 自分に関係があるか。新しい発見があるか | 導入の具体、意外な事実、図 | 長い前置き、内輪の言葉 |

## 4. 時間別の台本

| 版 | 中身 | 目安 |
|---|---|---|
| 30秒 | 結論とAsk、最も強い理由1つ | 150字前後 |
| 3分 | 30秒版＋理由3つ＋最大のリスクと対応＋次の一歩 | 900字前後 |
| 10分 | 3分版＋データ・事例・選択肢の比較・工程 | スライド6〜8枚 |
| 質疑 | 想定問答（費用、効果、他都市、リスク、なぜ今、やめる条件） | 1問30秒で答える |

先に30秒版を書く。30秒で言えない話は、10分かけても伝わらない。

## 5. 仕上げの点検

- [ ] Askが、冒頭と締めにある（誰に、何を、いつまでに）
- [ ] 結論が1文で言える。根拠は3つ以内
- [ ] 見出しを通読して、話が通る。見出しは結論の文
- [ ] 山場が1つ決まっている
- [ ] 最も強い反論への答えがある
- [ ] 「やらない場合」「他の案」との比較がある
- [ ] 数字に、出典・時点・比べる相手がある
- [ ] 事実・推測・意見が分かれている
- [ ] 鍵となる言葉・数字・期限の表現が、全体で同じ
- [ ] 読み手の言葉で書かれている
- [ ] 誇張・作り話・都合のよい引用がない
