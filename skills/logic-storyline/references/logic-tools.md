# 論理の道具

## 1. 問いを分ける（イシューツリー）

大きな問いを、答えの出せる小さな問いに分ける。分け方の切り口は、目的で選ぶ。

| 切り口 | 例 | 向く場面 |
|---|---|---|
| 足し算・掛け算に分ける | 収入＝単価×件数、費用＝固定費＋変動費 | 数字の問題 |
| 流れに分ける | 認知→来訪→利用→再訪 | どこで詰まっているかを探す |
| 主体に分ける | 行政／事業者／住民 | 役割と利害の整理 |
| 対立軸に分ける | 効果／費用／実現性／リスク | 案の比較 |
| 原因に分ける（なぜを重ねる） | なぜ利用が少ないか→知られていない／行きにくい／魅力がない | 原因の特定 |
| 時間に分ける | 短期／中期／長期 | 工程、段階的な実施 |

漏れと重なりを点検する方法：「その他」に何が入るかを考える。2つの枝に同じものが入らないかを見る。切り口を途中で変えない。

## 2. 「だから何か」「なぜそう言えるか」

- 事実を並べただけの文に、「だから何か」を問う。答えが、見出しになる。
- 3段階で深める：観察（何が起きているか）→ 解釈（何を意味するか）→ 行動（何をすべきか）。資料の見出しは、解釈か行動の段で書く。
- 例：「利用者は前年比12%減」（観察）→「駅から遠い2施設に減少が集中しており、立地が原因」（解釈）→「2施設の機能を駅前に集約する」（行動）。

## 3. 推論の型

| 型 | しくみ | 弱点 |
|---|---|---|
| 演繹 | 一般的な規則＋個別の事実→結論 | 規則（前提）が誤っていれば、全体が誤る |
| 帰納 | 複数の事実→共通する傾向 | 事例の偏り、数の不足。反例1つで揺らぐ |
| 仮説形成 | 観察された事実を、最もよく説明する仮説を立てる | 他の説明の可能性。検証が要る |
| 類推 | 似た事例で成り立つ→本件でも成り立つ | 似ている点と、違う点の見極め |

行政の資料で最も多い穴は、**類推の乱用**（他都市で成功したから、本市でも）と、**帰納の不足**（1〜2例からの一般化）。

## 4. 論証の点検（主張・データ・論拠）

| 要素 | 問い | 例 |
|---|---|---|
| 主張 | 何を言いたいか | 窓口を一本化すべき |
| データ | 根拠となる事実は何か | 手続に平均45日かかり、3課を回る |
| 論拠 | そのデータが、なぜ主張を支えるのか（隠れた前提） | 日数の主因は、課をまたぐ調整である |
| 裏付け | 論拠は、何で支えられるか | 工程ごとの日数の実測、他都市の一本化後の実績 |
| 限定 | どの範囲で成り立つか | 定型的な申請に限る |
| 反証 | 成り立たない条件は何か | 法令上、所管の判断が省けない案件 |

論拠が書かれていない資料は、読み手が自分の前提で補うため、誤解と反論を招く。

## 5. 誤りの型（点検表）

| 型 | 内容 | 行政資料での例 |
|---|---|---|
| 相関と因果の混同 | 一緒に動くものを、原因と結果と見なす | 「イベント実施地区は地価が上昇」 |
| 前後即因果 | 後に起きたから、前の出来事が原因 | 「施策開始後に来街者が増えた」 |
| 逆の因果 | 原因と結果が逆 | 「公園の多い地区は健康」（健康な人が選んで住む） |
| 性急な一般化 | 少数の例から全体を語る | 「先進2都市で成功」 |
| 生存者バイアス | 残ったものだけを見る | 成功事例集だけで判断する |
| 都合のよい証拠集め | 結論に合う情報だけを集める | 反対意見・失敗例の欠落 |
| 誤った二分法 | 選択肢を2つに限る | 「実施か、何もしないか」 |
| 論点のすり替え | 問いと別のことに答える | 効果を問われ、取組の量を答える |
| 循環論法 | 結論を、前提に使う | 「重要だから優先する。優先すべきなのは重要だから」 |
| 権威への依存 | 誰が言ったかで、正しさを決める | 「国の方針だから」だけで、本市での必要性を示さない |
| 滑りやすい坂 | 小さな一歩が、必ず極端な結果に至るとする | 「一度認めれば、全て認めることになる」 |
| 合成・分割の誤り | 部分の性質を全体に、全体の性質を部分に当てる | 市全体の傾向を、各区に当てはめる |
| 基準率の無視 | もとの割合を考えずに、割合を読む | 「相談件数が倍増」（もとが数件） |
| 多義語のすり替え | 途中で、言葉の意味が変わる | 「公共性」「連携」「活性化」 |
| サンクコスト | 既に使った費用を理由に、続ける | 「ここまで投資したのだから」 |

## 6. 数字の扱い

- 比べる相手を置く（前年、他都市、目標、全国平均）。単独の数字は、大きいか小さいか分からない。
- 割合と実数を併記する。母数を書く。
- 1人あたり、1件あたり、1日あたりに直すと、実感が出る。
- 推計・目標・実績を、同じ書き方で並べない。
- 端数は、判断に要る桁まで丸める。ただし、元の値と出典は、注に残す。
- グラフは、1枚で1つのことを言う。見出しに、読み取ってほしい結論を書く（作り方は `dataviz`）。

## 7. 文章の作法

- 1文1義。主語と述語を近づける。1文は、おおむね60字以内。
- 段落の最初の文に、その段落の結論を書く。
- 接続の言葉（したがって、一方で、ただし、なぜなら）を省かない。論理の関係は、接続の言葉に現れる。
- あいまいな言葉を、具体に置き換える（「推進する」→誰が、何を、いつまでに。「適切に」→基準は何か。「等」→残りは何か）。
- 約束の強さを使い分ける（「実施する」「検討する」「研究する」）。
- 専門用語、略語、庁内用語は、初出で説明する。
