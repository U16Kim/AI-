# 因果推論：施策の効果を測る

## 1. 考え方

- 知りたいのは「施策を受けた場合」と「受けなかった場合」の差。同じ対象で両方は観測できないため、**比較相手をどう作るか**がすべて。
- 交絡（原因と結果の両方に効く第三の要因）を断つ方法が、識別戦略。
- 因果の図（DAG）を描き、「何を調整すべきか」「何を調整してはいけないか」を決める。施策の結果として変わる変数（中間変数）や、原因と結果の両方から影響を受ける変数（合流点）を調整すると、かえって偏る。

## 2. 手法の早見表

| 手法 | 使える状況 | 中心となる前提 | 確かめること |
|---|---|---|---|
| 無作為化比較試験（RCT） | 対象を無作為に分けられる | 割付が無作為 | 群のバランス、脱落、周囲への波及 |
| 回帰不連続（RDD） | 基準値（年齢、所得、点数、境界線）で対象が決まる | 基準値の前後で、他の条件が連続 | 基準値付近の操作、帯域幅を変えた結果 |
| 差の差（DiD） | 施策の前後×対象と非対象のデータがある | 平行トレンド（施策がなければ同じ動き） | 施策前の動きの図、イベントスタディ、プラセボ |
| 合成コントロール | 対象が1つ（1市・1地区）で、比較候補が複数 | 施策前の動きを、他地域の重み付き平均で再現できる | 施策前の当てはまり、プラセボ（他地域を対象と見立てる） |
| 操作変数（IV） | 施策の受けやすさだけを動かす外的な要因がある | その要因は、施策を通じてのみ結果に効く | 第1段階の強さ、除外制約の説明 |
| 傾向スコア（マッチング・重み付け） | 対象になる理由が観測変数で説明できる | 未観測の交絡がない | バランスの確認、重なり、感度分析 |
| 二重に頑健な推定・DML | 変数が多い | 同上（モデルの誤りに強い） | 交差適合、結果の安定性 |
| 中断時系列 | 施策の時点が明確で、長い時系列がある | 同時期に他の出来事がない | 季節性、自己相関、対照系列 |

**導入時期がずれる施策の差の差**：単純な二方向固定効果モデルは、効果が時期や対象で違うと偏ることが知られている。Callaway–Sant'Anna、Sun–Abraham などの推定量を使う（Pythonは `differences`、Rは `did`・`fixest::sunab`）。

## 3. 差の差の実装

```python
# 誰が：分析担当者が／どのアプリで：JupyterLab か Google Colab で
# 何を：施策の対象地区と非対象地区の、前後のデータを／どうする：差の差で効果を推定する
# 事前に: pip install linearmodels
import pandas as pd, numpy as np
import statsmodels.formula.api as smf

# df の列: unit(地区ID), year(年), y(成果指標), treated(対象地区=1), post(施策後=1)
# 1) まず図で、施策前の動きが並行かを見る
trend = df.groupby(["year", "treated"])["y"].mean().unstack()
trend.plot(marker="o", title="施策前後の推移（対象・非対象）")

# 2) 差の差の推定（地区ごとに標準誤差をまとめる）
m = smf.ols("y ~ treated * post", data=df).fit(
        cov_type="cluster", cov_kwds={"groups": df["unit"]})
print(m.summary().tables[1])      # treated:post の係数が効果

# 3) イベントスタディ：施策の何年前・何年後かごとの効果（施策前が0付近なら前提を支持）
df["rel"] = df["year"] - policy_year
df["rel"] = df["rel"].clip(-4, 4)
es = smf.ols("y ~ C(rel, Treatment(reference=-1)):treated + C(unit) + C(year)",
             data=df).fit(cov_type="cluster", cov_kwds={"groups": df["unit"]})
```

コードの意味：①対象と非対象の平均を年ごとに線で描き、施策前に同じ向きで動いていたかを目で確かめる。②`treated * post` は「対象か」「施策後か」と、その掛け合わせを入れる書き方で、掛け合わせの係数が施策の効果になる。`cluster` は、同じ地区のデータが似ることを踏まえて誤差の幅を広げる指定。③施策の1年前を基準に、各年の差を出す。施策前の年の係数が0から離れていれば、平行トレンドの前提が疑わしい。

## 4. 傾向スコアと二重に頑健な推定

```python
# 何を：補助を受けた事業者と受けていない事業者を／どうする：似た者同士で比べる
import numpy as np
from sklearn.linear_model import LogisticRegression, LinearRegression

X, t, y = df[covs].values, df["treated"].values, df["y"].values
ps = LogisticRegression(max_iter=1000).fit(X, t).predict_proba(X)[:, 1]   # 対象になる確率
ps = np.clip(ps, 0.05, 0.95)                                             # 極端な重みを抑える

m1 = LinearRegression().fit(X[t == 1], y[t == 1]).predict(X)             # 受けた場合の予測
m0 = LinearRegression().fit(X[t == 0], y[t == 0]).predict(X)             # 受けない場合の予測
aipw = np.mean(m1 - m0 + t * (y - m1) / ps - (1 - t) * (y - m0) / (1 - ps))
print("平均的な効果（AIPW）:", round(aipw, 3))
```

コードの意味：`ps` は「この属性なら、どのくらい対象になりやすいか」。`m1`・`m0` は結果の予測。最後の式は、両方を組み合わせ、どちらかのモデルが正しければ偏りが小さくなる推定量。重み付け後に、群の属性がそろったか（標準化平均差が0.1未満か）を必ず確認する。未観測の要因には対応できないため、Rosenbaumの範囲やE値で感度分析を付ける。

道具：`DoWhy`（因果の図から推定まで）、`EconML`（効果の個人差）、`CausalImpact`、Rの `MatchIt`・`WeightIt`・`Synth`・`rdrobust`。

## 5. 落とし穴

| 落とし穴 | 例 | 対処 |
|---|---|---|
| 選択バイアス | 意欲の高い事業者が補助に応募する | 応募者内の比較、基準点の前後、落選者との比較 |
| 平均への回帰 | 事故の多い交差点に対策→翌年は自然に減る | 対照群、複数年の平均 |
| 波及効果 | 対象地区の施策が隣の地区に影響する | 緩衝帯を除く、波及を明示的に推定 |
| 同時期の出来事 | 施策と同時に景気が変わる | 対照群、プラセボ指標 |
| 予期による行動変化 | 発表時点で行動が変わる | 基準時点を発表前に置く |
| 悪い調整 | 施策で変わる変数を調整する | 因果の図で確認 |
| 外的妥当性 | 1地区の結果を全市に当てはめる | 対象の違いを明記、複数地区で再現 |
| 多数の指標から選ぶ | 効果の出た指標だけ報告 | 主要指標を事前に決める（事前登録） |

## 6. 行政での使い方

- **制度設計の段階で、評価の設計を入れる**：段階的な導入、抽選、基準値による線引き、導入前のデータ取得。事後に比較相手を探すより、はるかに確かな評価になる。
- 効果の大きさは、費用と並べて示す（費用対効果）。効果が確認できない場合も、「検出できる大きさの下限」を報告する。
- ロジックモデル（投入→活動→産出→成果）のどの矢印を検証したのかを明示する。
