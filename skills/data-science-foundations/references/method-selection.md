# 手法選択の早見表

## 1. 記述と比較（検定）

| 知りたいこと | データ | まず使う | 前提が怪しいとき |
|---|---|---|---|
| 2群の平均の差 | 連続・独立 | ウェルチのt検定 | マン・ホイットニーのU検定、並べ替え検定 |
| 同じ対象の前後差 | 連続・対応あり | 対応のあるt検定 | ウィルコクソンの符号付順位検定 |
| 3群以上の平均の差 | 連続 | 分散分析＋多重比較 | クラスカル・ウォリス検定 |
| 割合の差 | 二値 | カイ二乗検定、割合の差の信頼区間 | フィッシャーの正確検定（件数が少ない） |
| 2変数の関係 | 連続×連続 | ピアソンの相関 | スピアマンの順位相関 |
| 分布の形 | 連続 | ヒストグラム、QQプロット | 検定より、図で見る |

- 検定は「差がないと仮定したとき、このデータが出る珍しさ」を測るだけ。**効果量（差の大きさ）と信頼区間を必ず併記する。**
- 件数が多いと、意味のない小さな差でも有意になる。件数が少ないと、大きな差でも有意にならない。
- 多数の検定を行うときは、補正する（ボンフェローニ、ホルム、偽発見率の制御）。

## 2. 回帰モデル

| 目的変数 | モデル | 係数の読み方 |
|---|---|---|
| 連続 | 線形回帰 | 説明変数が1増えたときの平均的な増減 |
| 二値（起きた／起きない） | ロジスティック回帰 | オッズ比。確率の差で示す方が伝わる（平均限界効果） |
| カウント（件数） | ポアソン回帰、負の二項回帰（ばらつきが大きいとき） | 率の比。人口などをオフセットに入れる |
| 割合（0〜1） | ベータ回帰、分数ロジット | — |
| 順序（5段階評価） | 順序ロジット | — |
| 生存時間（〜までの期間） | カプラン・マイヤー、コックス比例ハザード | ハザード比。打切りを扱える |
| 階層のあるデータ（区の中の町丁、学校の中の生徒） | マルチレベル（混合効果）モデル | 群内と群間のばらつきを分ける |
| パネル（同じ対象を複数時点） | 固定効果モデル | 対象ごとの変わらない特性を取り除く |
| 空間データ | 空間ラグ・空間誤差モデル、地理的加重回帰 | 近隣の影響、係数の地域差 |

点検：残差の図、外れ値と影響点、多重共線性（VIF）、標準誤差（不均一分散・クラスターに頑健なもの）、交互作用の読み方。

## 3. 時系列

| 目的 | 手法 |
|---|---|
| 傾向と季節性を分ける | STL分解 |
| 短期予測 | 指数平滑法（ETS）、ARIMA・SARIMA、Prophet |
| 多数の系列・外部変数あり | 勾配ブースティング（ラグ特徴量）、状態空間モデル |
| 介入の影響 | 中断時系列分析、ベイズ構造時系列（CausalImpact） |
| 異常検知 | 季節調整後の残差、変化点検出 |

注意：定常性、自己相関、見せかけの回帰（傾向のある2系列は無関係でも相関する）、評価は時間順の分割で行う。

## 4. 分類・クラスタリング・次元削減

| 目的 | 手法 | 注意 |
|---|---|---|
| 似たもの同士に分ける | k-means、階層クラスタリング、混合ガウス、DBSCAN | 標準化が要る。群の数は、指標と解釈のしやすさの両方で決める |
| 変数をまとめる | 主成分分析、因子分析 | 主成分の意味付けは後付けになりやすい |
| 可視化のための圧縮 | UMAP、t-SNE | 距離や群の大きさに意味を読み込みすぎない |
| 文章の分類 | 埋め込み＋分類器、トピックモデル、LLM | 人手で確かめた正解データで精度を測る |

## 5. 空間統計

- 空間的自己相関：モランのI（全体）、ローカルモラン・Getis-OrdのGi*（ホットスポット）。
- 距離は投影座標系で測る（関東は平面直角座標系9系、EPSG:6677）。
- 集計単位を変えて結論が保たれるかを確かめる（可変単位地区問題）。
- 到達圏は、直線距離ではなく道路網で測る（OSMnx、QGISのネットワーク解析）。

## 6. ベイズ統計を使う場面

件数が少ない小地域の推定（階層モデルで周辺から情報を借りる）、事前の知見を入れたい場合、結果を「確率」で伝えたい場合（「効果がプラスである確率は87%」）。道具は PyMC、Stan、brms。

## 7. サンプルサイズと検出力

```python
# 誰が：分析担当者が／どのアプリで：JupyterLab か Google Colab で
# 何を：2群比較に必要な件数を／どうする：効果の大きさごとに計算する
from statsmodels.stats.power import TTestIndPower, NormalIndPower
from statsmodels.stats.proportion import proportion_effectsize

# 平均の差：効果量d（差÷標準偏差）が0.2・0.5・0.8のとき
for d in [0.2, 0.5, 0.8]:
    n = TTestIndPower().solve_power(effect_size=d, alpha=0.05, power=0.8)
    print(f"効果量{d}: 1群あたり約{n:.0f}件")

# 割合の差：利用率が10%から13%に上がることを見つけたいとき
h = proportion_effectsize(0.13, 0.10)
print("割合の差:", round(NormalIndPower().solve_power(effect_size=h, alpha=0.05, power=0.8)), "件／群")
```

コードの意味：`solve_power` は「この大きさの差を、8割の確率で見つけるには何件要るか」を逆算する。`alpha=0.05` は、差がないのに「ある」と言ってしまう確率の上限。効果が小さいほど、必要な件数は急に増える。

## 8. R・SQLでの対応

- R：`t.test`、`glm`、`lme4::lmer`、`fixest::feols`（固定効果・差の差）、`survival`、`forecast`／`fable`、`sf`、`spdep`。
- SQL（PostgreSQL）：集計は `GROUP BY`、順位や移動平均は窓関数（`ROW_NUMBER`、`LAG`、`AVG() OVER`）、分位は `PERCENTILE_CONT`、空間は PostGIS（`ST_DWithin`、`ST_Intersects`）。分析の前処理をSQLで済ませ、モデルはPython・Rで作る分担が扱いやすい。
