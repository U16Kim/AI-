# 一次情報の場所と調べ方

URLは変わることがある。開けない場合は、名称で検索して現在の場所を確かめる。

## 1. 法令

| 情報 | 場所 | 使い方 |
|---|---|---|
| 現行の法律・政令・省令 | e-Gov法令検索 https://laws.e-gov.go.jp/ | 法令名で検索。施行日を切り替えて、未施行の改正や過去の条文も見られる |
| 改正の経緯、法案の審議 | 日本法令索引（国立国会図書館）https://hourei.ndl.go.jp/ | いつ、どの法律で改正されたか |
| 立法趣旨・国会答弁 | 国会会議録検索システム https://kokkai.ndl.go.jp/ | 条文の趣旨を国会答弁で裏付ける |
| 公布された法令の原文 | 官報 https://www.kanpou.go.jp/ | 公布日と正文の確認 |
| 告示・通知・ガイドライン | 所管省庁のサイト | 「技術的助言」「運用指針」「Q&A」。発出日と番号を控える |
| 意見公募の結果 | e-Govパブリック・コメント https://public-comment.e-gov.go.jp/ | 政省令の考え方、意見への回答 |
| 条例・規則 | 各自治体の例規集 | 川崎市は `kawasaki-admin-reference`、東京都・横浜市は `metro-gov-reference` |

## 2. 判例・裁決

| 情報 | 場所 | 使い方 |
|---|---|---|
| 最高裁・下級審の裁判例 | 裁判所ウェブサイトの裁判例検索 https://www.courts.go.jp/ | 裁判所・日付・事件番号・キーワードで検索。全ての判決が載っているわけではない |
| 行政不服審査の裁決・答申 | 総務省の行政不服審査裁決・答申検索データベース | 行政不服審査会の答申。自治体の運用の参考 |
| 税の裁決 | 国税不服審判所の公表裁決事例 | 税務の論点 |
| 個人情報 | 個人情報保護委員会のガイドライン・Q&A・公表事案 | 漏えい時の対応、行政機関等の義務 |
| 競争・取引 | 公正取引委員会の報道発表・ガイドライン | 入札談合、官製談合、取引適正化 |
| 情報公開・個人情報の答申 | 各自治体の審査会答申 | 不開示の判断の実例 |

有料の判例データベース（判例秘書、Westlaw Japan、D1-Law、LEX/DB等）にしかない裁判例は、ここからは確認できない。その場合は「公開情報では確認できない」と書く。

## 3. 行政解釈・実務の手がかり

- 総務省の通知（地方自治法の技術的助言）、行政実例、逐条解説。裁判所を拘束しないが、実務の標準。
- 国土交通省の都市計画運用指針、開発許可制度運用指針、建築基準法の技術的助言。
- 内閣府のPFI関係ガイドライン、指定管理者制度に関する総務省通知。
- 会計検査院の検査報告、自治体の包括外部監査報告書、住民監査請求の監査結果（実際に問題にされた事例の宝庫）。

## 4. 調べ方のこつ

1. 正式名称を先に確かめる（通称と正式名称が違う法律が多い）。
2. 定義規定（多くは第2条）を読む。日常語と意味が違うことがある。
3. 本則だけでなく、附則（施行日、経過措置）と、委任を受けた政令・省令を読む。「政令で定める」とあれば、施行令を開く。
4. 準用規定は、読み替えた後の文を自分で書き出す。
5. 判例は、判決日で検索するのが最も確実。通称だけでは別事件に当たることがある。
6. 改正が多い分野（個人情報、建築、労働、会社、税）は、施行日を必ず書く。

## 5. 引用の書き方

- 法令：「地方自治法（昭和22年法律第67号）第234条第2項」。初出は正式名称、以後は略称可。
- 判例：「最高裁昭和62年3月20日第二小法廷判決」。確認できた場合に限り、事件番号や掲載誌（民集〇巻〇号〇頁）を添える。
- 通知：「令和〇年〇月〇日付け総行行第〇号 総務省自治行政局長通知」。
- ウェブ：ページ名、URL、確認日。
- 確認の印を付ける：【原文確認済】【検索結果で確認】【未確認（記憶による）】。
