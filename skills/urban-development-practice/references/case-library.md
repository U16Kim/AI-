## 事例を使うときの確認表

| 確認項目 | 理由 |
|---|---|
| 人口規模・地価水準・財政力は近いか | 事業性の前提が違う |
| 根拠となる制度（法・条例）は日本にあるか | 強制徴収や税の仕組みは持ち込めないことがある |
| 成果は誰が、どう測ったか | 事業主体の自己評価だけでは弱い |
| うまくいかなかった点、批判は何か | 説明のときに必ず聞かれる |
| 時点はいつか | 開業直後の数字と、数年後の数字は違う |
