# 都市計画法・建築基準法ほか：論点の地図

**使い方**：論点の見落としを防ぐための索引。条番号は覚え書きであり、引用前に e-Gov法令検索（https://laws.e-gov.go.jp/）で現行条文を確認する。数値は法律の本則のもので、条例・地区計画による上乗せが別にある。

## 1. 都市計画法

| 論点 | 条 | 要点・見落としやすい点 |
|---|---|---|
| 都市計画区域・区域区分 | 5条・7条 | 市街化区域と市街化調整区域。調整区域は原則として建築・開発を抑える |
| マスタープラン | 6条の2（区域マス）・18条の2（市町村マス） | 個別の都市計画は、これに即することが求められる。提案の根拠付けに使う |
| 用途地域ほか地域地区 | 8条・9条 | 用途地域は13種類（田園住居地域は平成30年施行）。高度地区、防火地域、特別用途地区、景観地区なども地域地区 |
| 地区計画 | 12条の4・12条の5 | 地区整備計画が定められ、建築条例（建築基準法68条の2）になっていれば確認の対象。届出・勧告にとどまる区域もある |
| 再開発等促進区 | 12条の5第3項 | 工場跡地などの土地利用転換で、容積・用途を見直す器 |
| 都市施設・市街地開発事業 | 11条・12条 | 都市計画施設の区域内は建築に許可が要る（53条） |
| 決定手続 | 15条〜19条 | 案の縦覧と意見書（17条）、都市計画審議会。決定権者（都道府県か市町村か）を先に確認する。指定都市の特例は87条の2 |
| 都市計画の提案 | 21条の2 | 土地所有者・まちづくりNPO等が提案できる。面積と同意の要件あり |
| 開発許可 | 29条・33条・34条 | 市街化区域は原則1,000㎡以上（三大都市圏の既成市街地等は500㎡以上。条例で引下げ可）。技術基準は33条、調整区域の立地基準は34条 |
| 都市計画事業 | 59条〜 | 事業認可により、収用の効果が生じる |

## 2. 建築基準法

| 論点 | 条 | 要点・見落としやすい点 |
|---|---|---|
| 建築確認・検査 | 6条・6条の2・7条・7条の3 | 指定確認検査機関の確認も、建築主事の確認とみなされる。完了検査と検査済証 |
| 確認の対象の見直し | 6条1項 | 令和7年4月施行の改正で、いわゆる4号特例が縮小（木造2階建て等は審査省略の対象外に）。同日、省エネ基準への適合が原則すべての新築で義務化（建築物省エネ法） |
| 既存不適格 | 3条2項・86条の7 | 増改築・用途変更で、どこまで現行基準に合わせるかが論点。緩和の範囲は政令で細かく決まる |
| 用途変更 | 87条 | 特殊建築物への用途変更で、その部分が200㎡を超えると確認が要る（令和元年施行の改正で100㎡から引上げ）。確認が不要でも、基準への適合は必要 |
| 一時的な利用 | 85条・87条の3 | 仮設建築物の許可、既存建築物の一時的な用途変更。社会実験やイベントで使う |
| 道路・接道 | 42条・43条 | 2項道路の後退、43条2項の認定・許可。敷地の価値と計画の可否を左右する |
| 用途制限 | 48条・別表第二 | ただし書許可（公聴会・建築審査会の同意）で例外あり |
| 容積率・建蔽率 | 52条・53条 | 容積率は指定値と前面道路幅員による値の小さい方。特定道路、共用廊下等の不算入などの特例 |
| 高さ・斜線・日影 | 55条・56条・56条の2 | 天空率（56条7項）で斜線を置き換えられる。日影は条例で対象区域・時間を指定 |
| 総合設計 | 59条の2 | 公開空地と引換えに容積・高さを緩和。自治体の許可要綱で運用が決まる |
| 一団地・連担 | 86条 | 複数敷地を一つとみなす。権利関係の整理が要る |
| 防火・耐火 | 27条・61条 | 木造・混構造の計画、用途変更で論点になる |
| 定期報告・違反是正 | 12条・9条 | 既存建物を使う事業では、定期報告の履歴が状態を知る手がかり |
| 建築審査会 | 78条 | 許可の同意、審査請求の裁決 |
| 建築協定 | 69条〜 | 住民発意のルール。地区計画との使い分け |

**体制の変更（令和6年4月施行）**：建築副主事の新設、建築基準適合判定資格者の一級・二級の区分。確認検査の体制に関わる（詳細は `qualification-knowledge`）。

## 3. 都市再生特別措置法・その他の面的制度

| 制度 | 根拠 | 要点 |
|---|---|---|
| 都市再生緊急整備地域・特定都市再生緊急整備地域 | 都市再生特別措置法 | 政令で指定。税制・金融支援、都市計画の特例の入口 |
| 都市再生特別地区 | 同法36条 | 既存の用途・容積・高さ等の規制を外し、提案に基づき個別に定める。公共貢献の評価が鍵 |
| 都市再生整備計画・滞在快適性等向上区域 | 同法46条 | 交付金、まちなかウォーカブルの特例（民地の開放、道路・公園の特例） |
| 都市再生推進法人・都市利便増進協定 | 同法 | エリアマネジメント団体の公的な位置付け |
| 立地適正化計画 | 同法81条 | 居住誘導区域・都市機能誘導区域。届出・勧告。防災指針 |
| 景観計画・景観地区 | 景観法 | 届出・勧告、変更命令。屋外広告物条例と併せて確認 |
| 緑地・農地 | 都市緑地法、生産緑地法 | 特定生産緑地、市民緑地認定制度 |
| 宅地造成・盛土 | 宅地造成及び特定盛土等規制法 | 令和5年5月施行。規制区域の指定状況を確認 |
| 土壌汚染 | 土壌汚染対策法 | 3,000㎡以上の形質変更の届出など。工場跡地の再開発で必須 |
| 防災 | 土砂災害防止法、水防法、津波防災地域づくり法 | 災害レッドゾーンでの開発規制（都市計画法33条・34条の改正）と重説 |
| 環境影響評価 | 環境影響評価法・条例 | 規模要件は条例で上乗せされる。工程への影響が大きい |
| バリアフリー | バリアフリー法 | 特別特定建築物の適合義務。条例で対象拡大 |
| 駐車場 | 駐車場法・附置義務条例 | 附置義務の緩和・集約化の制度がある自治体あり |
| 文化財 | 文化財保護法 | 埋蔵文化財包蔵地は工事前に届出。試掘で工程が延びる |

## 4. 確認時に使う一次情報

- 法令：e-Gov法令検索。改正の経緯と未施行条文も見る。
- 国の運用：国土交通省の技術的助言（通知）、都市計画運用指針、開発許可制度運用指針。
- 自治体：都市計画情報の地図サービス、例規集、開発指導要綱、建築基準条例・取扱基準。
- 判例：`japan-law-research` の `references/key-precedents.md`（処分性・原告適格・裁量）。
