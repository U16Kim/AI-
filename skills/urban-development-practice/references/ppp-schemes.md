## 2. PFI法の手続（地方公共団体の場合）

実施方針の策定・公表（5条）→ 特定事業の選定（7条。VFMの評価を公表）→ 民間事業者の選定（8条。総合評価一般競争入札か公募型プロポーザル）→ 仮契約 → 議会の議決（12条。一定規模以上）→ 事業契約 → 設計・建設 → 運営・モニタリング → 終了。

- 債務負担行為の設定（地方自治法214条）の時期を、予算編成の日程と合わせる。
- 公の施設であれば、指定管理者の指定の議決（244条の2）が別に要ることがある。
- 優先的検討規程（一定規模以上の事業でPPP/PFIを優先して検討するしくみ）の対象かを確認する。川崎市の扱いは `kawasaki-admin-reference`。

## 3. VFMの考え方

- VFM ＝ PSC（公共が自ら行う場合の事業期間全体の公的負担の現在価値）− PFI事業のLCC（PFIで行う場合の公的負担の現在価値）。プラスならPFIが有利。
- **割引率**：内閣府の「VFM（Value For Money）に関するガイドライン」の考え方に従う。公共事業の費用便益分析で使う社会的割引率（国土交通省の技術指針では4%を基本とし、令和5年の改定で1%・2%を参考比較として設定できるとされた）とは別の概念であり、混同しない。採用した割引率と根拠を必ず書き、割引率を動かした感度分析を付ける。
- **結論を左右する前提**：建設費・運営費の削減率、資金調達コストの差、リスク調整額、税・補助金の扱い（イコールフッティング）。削減率を根拠なく10%と置くと、VFMは機械的に出る。類似事例の実績値で裏付ける。
- VFMが出ても、競争（応募者数）がなければ実現しない。サウンディング（対話型市場調査）で参加意向を確かめる。

```python
# 誰が：検討担当者が／どのアプリで：JupyterLab か Google Colab で
# 何を：PSCとPFI-LCCを／どうする：現在価値に直してVFMを概算し、前提を動かす
import pandas as pd

def pv(flows, r):                      # 各年の支出を現在価値に直して合計する
    return sum(f / (1 + r) ** t for t, f in enumerate(flows, start=1))

def vfm(capex, opex, years, r, cut_capex, cut_opex, spread, risk_adj):
    """capex:建設費 opex:年間運営費 r:割引率 cut_*:民間の削減率
    spread:民間資金の上乗せ金利相当(建設費に対する年率) risk_adj:PSCに加えるリスク調整額"""
    psc = pv([capex / years + opex] * years, r) + risk_adj
    lcc = pv([capex * (1 - cut_capex) / years * (1 + spread * years / 2)
              + opex * (1 - cut_opex)] * years, r)
    return round((psc - lcc) / psc * 100, 1)

rows = [{"削減率": c, "割引率": r, "VFM(%)": vfm(10_000, 300, 20, r, c, c, 0.01, 200)}
        for c in [0.03, 0.05, 0.10] for r in [0.01, 0.02, 0.04]]
print(pd.DataFrame(rows).pivot(index="削減率", columns="割引率", values="VFM(%)"))
```

簡易モデルであり、実際のVFM算定（年度別の資金収支、税、起債、交付税措置）の代わりにはならない。**「どの前提でVFMが消えるか」を見せるための道具**として使う。

## 4. リスク分担の原則

「そのリスクを最もよく管理できる者が負う」。次の表を事業ごとに埋める。

| リスク | 例 | 公 | 民 | 備考 |
|---|---|---|---|---|
| 制度・政策変更 | 法改正、施設方針の変更 | ○ | | 当該事業に直接関わる変更は公が負うのが通例 |
| 物価変動 | 資材・労務費・光熱費 | △ | △ | 改定のルール（指標・頻度・しきい値）を契約に書く。近年の最大の論点 |
| 需要変動 | 利用者数、料金収入 | 設計による | 設計による | 独立採算型は民。プロフィットシェア・ロスシェアの定め |
| 設計・建設 | 遅延、コスト超過、地中障害 | 一部 | ○ | 地中障害・土壌汚染は公が負う例が多い |
| 維持管理・運営 | 性能未達、修繕費の増 | | ○ | モニタリングと減額のしくみ |
| 不可抗力 | 災害、感染症 | ○ | △ | 民の負担の上限を定める |
| 資金調達 | 金利変動 | △ | ○ | 基準金利の確定日 |
| 事業終了 | 引継ぎ、原状回復、中途解除 | — | — | 終了時の施設の状態の基準を書く |

## 5. 指定管理者制度の論点

- 指定は行政処分であり、契約ではない。指定の議決が要る。協定で細部を定める。
- 利用料金制、自主事業、目的外使用許可との組合せで、収益の出し方が変わる。
- 期間が短いと投資が起きない。投資を求めるなら、期間と、投資の回収・買取りの定めを見直す。
- 物価・賃金の上昇への対応（指定管理料の改定条項）と、事故時の責任（国家賠償法2条との関係）を協定で整理する。

## 6. 公平性の確保（官民共創の実務で最も問われる点）

| 場面 | 確認すること |
|---|---|
| 民間からの提案を受けた | 提案の受付・対話の記録、知的財産の扱い、同じ機会を他者にも開いたか |
| 提案者と随意契約にしたい | 地方自治法施行令167条の2のどの号か。当たらなければ公募する |
| 実証実験から本格導入へ | 実証の参加者が本調達で有利にならない仕様か。実証結果の公開 |
| 協定を結ぶ | 排他的な内容になっていないか。市の義務と予算の裏付け |
| 公有財産を使わせる | 使用料・貸付料の根拠と減免の理由。議決の要否 |
| 名義・ロゴ・広報 | 後援名義等の基準、特定企業の宣伝に見えないか |
