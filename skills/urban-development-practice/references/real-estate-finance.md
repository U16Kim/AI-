# 不動産の評価と事業収支

ここでの計算は概算。公有財産の処分・貸付の価格、補償額は、不動産鑑定評価等の正式な手続による。

## 1. 価格の物差し

| 物差し | 根拠 | 性格 | 目安の関係 |
|---|---|---|---|
| 地価公示・都道府県地価調査 | 地価公示法、国土利用計画法施行令 | 正常価格の指標。1月1日／7月1日時点 | 基準 |
| 相続税路線価 | 国税庁の財産評価基本通達 | 相続税・贈与税の評価 | 公示価格の8割程度とされる |
| 固定資産税評価額 | 地方税法、固定資産評価基準 | 3年ごとの評価替え | 公示価格の7割程度とされる |
| 実勢価格・成約事例 | 不動産情報ライブラリ（国土交通省）等 | 個別事情を含む | 補正が要る |

「8割・7割」は制度上の目安であり、個別の土地では差がある。数字を使うときは、時点と出典を必ず書く。

## 2. 鑑定評価の三方式（不動産鑑定評価基準）

| 方式 | 求める価格 | 考え方 | 弱い場面 |
|---|---|---|---|
| 原価法 | 積算価格 | 再調達原価から減価を引く | 古い建物、収益物件 |
| 取引事例比較法 | 比準価格 | 似た取引を補正して比べる | 事例が少ない地域・特殊な物件 |
| 収益還元法 | 収益価格 | 将来の純収益を現在価値に直す（直接還元法／DCF法） | 収益が見通しにくい物件 |

## 3. 収益の基本式と指標

- NOI（純営業収益）＝ 総収入 − 空室損 − 運営費（管理費・修繕費・税・保険）。減価償却費と借入利息は引かない。
- 直接還元法：価値 ＝ 1年分の純収益 ÷ 還元利回り（キャップレート）。
- DCF法：各年のキャッシュフローと売却価値を、割引率で現在価値に直して合計する。
- IRR（内部収益率）：投資の年平均の利回り。NPV（正味現在価値）が0になる割引率。
- DSCR（元利金返済カバー率）＝ NOI ÷ 年間元利返済額。金融機関は一定以上を求める。
- LTV（借入比率）＝ 借入額 ÷ 物件価値。

```python
# 誰が：検討担当者が／どのアプリで：JupyterLab か Google Colab で
# 何を：賃貸事業のキャッシュフローを／どうする：IRRと感度を計算する
# 事前に: pip install numpy-financial
import numpy as np, numpy_financial as npf, pandas as pd

def project_cf(invest, rent0, occ, opex_ratio, growth, years, exit_cap, sale_cost=0.03):
    """invest:初期投資 rent0:満室時年間賃料 occ:稼働率 opex_ratio:運営費率
    growth:賃料の年変動率 exit_cap:売却時の還元利回り"""
    noi = [rent0 * occ * (1 - opex_ratio) * (1 + growth) ** t for t in range(years + 1)]
    cf = [-invest] + noi[:years]
    cf[-1] += noi[years] / exit_cap * (1 - sale_cost)   # 最終年に売却価値を加える
    return cf

base = dict(invest=3_000, rent0=260, occ=0.93, opex_ratio=0.25, growth=0.0, years=10, exit_cap=0.05)
print("IRR(基本)", round(npf.irr(project_cf(**base)), 4))

rows = []
for occ in [0.85, 0.90, 0.95]:
    for cap in [0.045, 0.05, 0.055]:
        p = {**base, "occ": occ, "exit_cap": cap}
        rows.append({"稼働率": occ, "売却利回り": cap, "IRR": round(npf.irr(project_cf(**p)), 4)})
print(pd.DataFrame(rows).pivot(index="稼働率", columns="売却利回り", values="IRR"))
```

コードの意味：`project_cf` が毎年の手取り収益を並べ、最終年に「その時点で売ったらいくらか」を足す。`npf.irr` がその並びから利回りを計算する。下の二重ループは、稼働率と売却時の利回りを変えたときに、結果がどれだけ動くかを表にしている。数値は例示（単位は百万円）。

## 4. 借地・借家（公有地活用で頻出）

| 類型 | 根拠（借地借家法） | 期間 | 要点 |
|---|---|---|---|
| 普通借地権 | 3条ほか | 30年以上 | 更新あり。正当事由がないと終了できない |
| 一般定期借地権 | 22条 | 50年以上 | 更新なし。特約は書面（電磁的記録を含む） |
| 事業用定期借地権 | 23条 | 10年以上50年未満 | 事業用の建物に限る。公正証書が必要。居住用は不可 |
| 建物譲渡特約付借地権 | 24条 | 30年以上 | 期間満了時に建物を地主が買い取る |
| 定期建物賃貸借 | 38条 | 定めによる | 書面による契約と、事前の書面説明が要る |

公有地の場合は、地方自治法の財産の区分（行政財産か普通財産か）で、貸付の可否と手続が先に決まる（238条の4、238条の5）。貸付料の減免、議会の議決の要否（96条、237条）、条例の定めを確認する。
