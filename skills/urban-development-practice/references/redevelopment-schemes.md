## 1. 手法の比較

| 手法 | 根拠法 | しくみ | 向く場面 | 主な関門 |
|---|---|---|---|---|
| 第一種市街地再開発事業 | 都市再開発法 | 権利変換（従前の権利を新しい建物の床に置き換える）。保留床の売却で事業費を賄う | 駅前、木造密集、細分化した土地 | 都市計画決定、組合設立の同意（権利者の3分の2以上など）、権利変換計画、保留床の買い手 |
| 第二種市街地再開発事業 | 同上 | 用地買収（管理処分）方式。公共性・緊急性の高い地区 | 防災上重要な大規模地区 | 施行者が限られる。資金と体制 |
| 土地区画整理事業 | 土地区画整理法 | 換地と減歩で道路・公園を生み出す。保留地の売却で事業費を賄う | 基盤未整備地、跡地、駅周辺 | 仮換地、移転補償、地価下落時の保留地処分 |
| 都市再生特別地区 | 都市再生特別措置法 | 民間提案で規制を個別に定める | 都心の大規模開発 | 公共貢献の評価、都市計画審議会 |
| 地区計画・再開発等促進区 | 都市計画法 | ルールで段階的に誘導。容積の見直しと公共施設整備を組み合わせる | 土地利用転換、段階開発 | 地権者合意、企画提案の協議 |
| 総合設計 | 建築基準法 | 公開空地と引換えに容積等を緩和 | 単独敷地の建替え | 許可要綱、近隣調整 |
| 防災街区整備事業 | 密集市街地整備法 | 権利変換で個別利用区も認める | 木造密集地域 | 合意形成 |
| 優良建築物等整備事業 | 要綱（補助事業） | 法定事業によらない共同化への補助 | 小規模な共同建替え | 補助要件 |
| マンション建替え・敷地売却 | マンション建替え円滑化法、区分所有法 | 決議と権利変換・売却 | 老朽マンション | 決議要件（区分所有法は令和7年に改正法が成立。施行日と要件は要確認） |

## 2. 市街地再開発事業の流れ（第一種・組合施行の例）

勉強会 → 準備組合 → 都市計画決定（高度利用地区等と事業の決定）→ 組合設立認可 → 権利変換計画の認可 → 明渡し・除却 → 工事 → 竣工・清算 → 組合解散。

各段階の論点：
- **準備段階**：事業協力者・参加組合員の選び方（透明性）。行政の関わり方（技術支援、調査費補助）。
- **都市計画**：容積の根拠と公共貢献。上位計画との整合。
- **権利変換**：従前資産の評価、借家人・営業者の補償、転出者の割合。
- **資金**：保留床処分金が主。補助金（社会資本整備総合交付金など）と公共施設管理者負担金。工事費上昇時の事業計画変更。
- **公共床**：行政が保留床を取得する場合は、取得の必要性・価格の妥当性・議決の要否を早期に整理する。

## 3. 事業収支の骨格（概算用）

```python
# 誰が：検討担当者が／どのアプリで：JupyterLab か Google Colab で
# 何を：再開発の概算収支を／どうする：工事費と床単価を動かして成立性を見る
import pandas as pd

def redevelopment_balance(gfa, saleable_ratio, floor_price, right_floor_ratio,
                          const_cost, soft_ratio, compensation, subsidy):
    """gfa:延床(㎡) saleable_ratio:専有率 floor_price:保留床単価(万円/㎡)
    right_floor_ratio:権利床の割合 const_cost:工事単価(万円/㎡)
    soft_ratio:調査設計・事務費・金利の工事費比 compensation:補償費(万円) subsidy:補助金等(万円)"""
    saleable = gfa * saleable_ratio
    reserve_floor = saleable * (1 - right_floor_ratio)   # 保留床
    income = reserve_floor * floor_price + subsidy
    cost = gfa * const_cost * (1 + soft_ratio) + compensation
    return {"保留床面積": reserve_floor, "収入": income, "支出": cost, "差引": income - cost}

rows = []
for c in [0.9, 1.0, 1.1, 1.2]:          # 工事費の倍率
    for p in [0.9, 1.0, 1.1]:           # 床単価の倍率
        r = redevelopment_balance(50000, 0.7, 150*p, 0.3, 60*c, 0.25, 800000, 800000)
        rows.append({"工事費": c, "床単価": p, "差引(億円)": round(r["差引"]/10000, 1)})
print(pd.DataFrame(rows).pivot(index="工事費", columns="床単価", values="差引(億円)"))
```

数値は例示であり、実際の単価は時点・地域・用途で大きく違う。入力値には必ず出典と時点を付ける。
