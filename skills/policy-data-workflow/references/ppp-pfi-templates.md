## 事業方式の選定（軽い順に検討する）

```
行政が手放せないもの（所有・料金決定・サービス水準）を先に決める
        ↓
運営だけを任せる        → 業務委託／包括的民間委託／指定管理者
公共空間・財産を使わせる → 設置管理許可／目的外使用許可／Park-PFI／貸付・定期借地
整備と運営を一括で任せる（資金は公共） → DB／DBO
整備と運営を一括で任せる（資金は民間） → PFI
        ├─ BTO：民間が建設 → 完成後に所有権を公共へ移す → 民間が運営
        ├─ BOT：民間が建設・所有して運営 → 事業終了時に公共へ移す
        ├─ BOO：民間が建設・所有・運営し、終了後も移さない
        └─ RO ：民間が既存施設を改修して運営
料金収入のある既存施設の運営を長期に任せる → 公共施設等運営権（コンセッション）
```

需要リスク（利用者数・料金収入の変動）を誰が負うかを、方式とは別に必ず決める。

## VFM（Value for Money）概算テンプレート

```python
# 誰が：検討担当者が／どのアプリで：JupyterLab か Google Colab で
# 何を：公共が自ら行う場合（PSC）とPFIの場合の公的負担を／どうする：現在価値で比べる
# 単位：百万円
PSC = {"建設費": 0, "維持管理費_年": 0, "運営費_年": 0, "リスク調整額": 0, "事業期間_年": 0}
PFI_LCC = {"サービス対価_年": 0, "公共側の経費_年": 0}

# 割引率：内閣府「VFMに関するガイドライン」の考え方に沿って設定し、根拠を書く。
# 公共事業の費用便益分析で使う社会的割引率（国土交通省の技術指針では4%を基本とし、
# 1%・2%を参考比較にできる）とは別の概念。混同しない。必ず複数の値で感度を見る。
discount_rates = [0.01, 0.02, 0.04]
years = PSC["事業期間_年"]

def pv(annual, rate, n):                 # 毎年の支出を現在価値に直して合計する
    return sum(annual / (1 + rate) ** t for t in range(1, n + 1))

for r in discount_rates:
    psc = PSC["建設費"] + pv(PSC["維持管理費_年"] + PSC["運営費_年"], r, years) + PSC["リスク調整額"]
    lcc = pv(PFI_LCC["サービス対価_年"] + PFI_LCC["公共側の経費_年"], r, years)
    if psc > 0:
        print(f"割引率{r:.0%}: PSC {psc:,.0f} / PFI-LCC {lcc:,.0f} / VFM {(psc - lcc) / psc * 100:.1f}%")
```

コードの意味：`pv` は、将来の毎年の支払いを「今のお金の価値」に直して足し合わせる関数。割引率を3通りに変えて、PSC（公共が行う場合）とPFI-LCC（PFIの場合）の差の割合（VFM）を出す。**建設費・運営費の削減率を根拠なく置くと、VFMは機械的にプラスになる。** 削減率は類似事例の実績で裏付け、割引率・削減率・金利差を動かしても結論が保たれるかを確かめる。これは概算であり、正式な算定（年度別の資金収支、税、起債、交付税措置）の代わりにはならない。

## リスク分担表

| リスク | 例 | 公 | 民 | 分担の考え方 |
|---|---|---|---|---|
| 需要変動 | 利用者数、料金収入 | | | 独立採算型は民。上振れ・下振れの分け方を定める |
| 設計・建設 | 遅延、費用超過、地中障害 | | | 地中障害・土壌汚染は公が負う例が多い |
| 維持管理・運営 | 性能未達、修繕費の増 | | | モニタリングと減額の定め |
| 法令・政策変更 | 法改正、方針の変更 | | | 当該事業に直接関わる変更は公 |
| 物価変動 | 資材・労務費・光熱費 | | | 改定の指標・頻度・しきい値を契約に書く |
| 金利変動 | 基準金利の確定まで | | | 確定日を決める |
| 不可抗力 | 災害、感染症 | | | 民の負担の上限を定める |
| 事業終了 | 引継ぎ、原状回復、中途解除 | | | 終了時の施設の状態の基準 |

原則：そのリスクを最もよく管理できる者が負う。

## 調達の流れ（PFI法による標準形）

```
事業の発案・優先的検討（簡易な検討 → 詳細な検討）
  ↓ 導入可能性調査、サウンディング（市場との対話）
実施方針の策定・公表（第5条）／債務負担行為の設定
  ↓
特定事業の選定・公表（第7条。VFMの評価）
  ↓
入札公告・募集要項の公表 → 質疑 → 提案の受付 → 審査 → 事業者の選定（第8条）
  ↓
基本協定 → 仮契約 → 議会の議決（第12条。一定規模以上）→ 事業契約
  ↓
設計・建設 → 運営・維持管理・モニタリング → 事業終了・引継ぎ
```

検討開始から契約まで、2〜3年かかるのが一般的。予算編成と議会の日程に合わせて逆算する（川崎市の日程は `kawasaki-admin-reference`）。
