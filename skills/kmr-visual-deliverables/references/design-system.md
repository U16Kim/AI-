# 設計値と視覚設計（型B・C・Dの政策説明スライド）

依頼者の基準は「**視覚的なインパクトは出す。ただし、上品さを欠くことは許されない**」。印象が強いだけの資料は、色・文字の大きさ・太さ・余白の釣り合いが崩れている。ここにある値が、このスキルの**唯一の正**である。`scripts/lib.js` と `scripts/audit.py` は、この値で作ってある。値を変えるときは、3か所を同時に直す。

根拠：KF R9実施方針（令和8年11月）で、3案の試作と3役のレビューを行い、インパクト重視の版（v5）を整え直した版（v6）で数値を確かめた（文字サイズ33種→13種、太字55%→39%、コントラスト不足あり→なし）。

## 1. 活字

**尺度（比およそ1.2）。使ってよいサイズは次の13個だけ。**

| pt | 役割 |
|---|---|
| 10.5 | 出典・頁・章名の注記（下限） |
| 12 | 図の注、表の本文、章名、札 |
| 14 | 本文、図中のラベル |
| 17 | リード、強調する本文、箱の小見出し |
| 21 | 見出し（箱の題） |
| 25 | 帯に載せる結論 |
| 30 | スライドタイトル、期限札 |
| 36・43 | 見出しの大字、KPIの数字 |
| 62・89・107・185 | 主役の活字 |

- 尺度外の値（13、16、27、28、300 など）は使わない。釣り合いが崩れる原因になる。
- 主役は本文14ptの約13倍（185pt）まで。それを超える文字は過大。
- **太字は、タイトル・見出し・ラベルだけ。** 太字は全体の4割以下（`audit.py` は、文字のまとまりの数で数える）。本文・表の中身・帯の補足は標準ウェイト。大きな文字ほど細く見せる（太い巨大文字は品を落とす）。
- **書体は2系統。** 本文・ラベルは Meiryo。主役の大字は、日本語が游明朝（Yu Mincho）、数字・欧文が Cambria。どちらも標準ウェイトで、太字にしない。
- 文字が収まらないときは、文言を削る。縮めない。

## 2. 余白と格子

- キャンバスは `LAYOUT_WIDE`（13.333×7.5インチ）。左右の余白は0.75インチ。本文の領域は縦1.9〜6.9。
- タイトル・リード・本文・出典の左端を、全頁で同じxにそろえる。頁ごとの左端の種類を少なくする（図の頁は除く）。
- 3列の段組みは、列間0.4インチ。
- 本文は左揃え。中央揃えは、箱の中のラベルと数字だけ。
- 文字が入る箱は、幅に1割の余裕を持たせる（描画環境で書体が変わり、幅がずれるため）。

## 3. 色

| 役 | 値 | 使い方 |
|---|---|---|
| 白 | `FFFFFF` | 印刷・回覧する資料の地（既定） |
| 紙 | `F4F6FA` | 投影が主の資料の地 |
| 夜 | `0B1730` | 全面濃色の頁、結論の帯 |
| ネイビー | `1F3A5F` | 主色（図の主役、見出しの帯） |
| 中 | `3F6C9E` | 補助。白い文字を載せられる下限の濃さ |
| 淡 | `8FB0D3` | 面・線だけ。紙や白の上の文字には使わない |
| 朱（淡色面） | `B93A14` | 期限・関門・Ask・推奨だけ |
| 朱（濃色面） | `F28A62` | 同上（札の字は夜色） |
| 濃色面の副文字 | `B7C4D9` | 濃色面の文字は、白とこの色の2色だけ |
| 濃色面の罫 | `2C3E5E` | 夜より少し明るい紺。色の濃淡だけで引く |

- **朱の意味を固定する。** 期限・関門・Ask・推奨だけに使い、1頁2か所まで。面積は全体の1割未満。彩度の高い朱（例 `C2410C`）は上品さを欠くので使わない。
- **主色は内容から導いて差し替えてよい**（環境なら深緑、福祉なら温かいテラコッタなど）。強い主色1＋抑えた地＋鋭い強調1、の構成は変えない。差し替えるのは `lib.js` の `P.main` と `P.main2`。
- コントラスト比は、文字4.5以上、24pt以上の大字は3以上。白い文字は `3F6C9E` 以上に濃い面に置く（`4F7CAC` は4.36で不足）。
- 黄・琥珀、警告色の平塗りは使わない。

## 4. 線と面

- 罫0.75pt、強調の罫1.5pt、矢印2pt、路線2.5pt。太い枠線は使わない。
- **線種で確かさを語る。** 実線＝確定、破線＝未確定・目標。
- **全面濃色の頁は3枚まで**（表紙＋山場2枚。山場は、効果・財政と、最終のAskが定石）。付録を付ける場合に限り、付録の扉を4枚目として加えてよい。
- 結論を載せる夜色の帯（左端から右端まで、高さ1インチ前後）は使ってよい。細い縦の色帯、タイトル下の線、文字の背後の飾りの帯は使わない。
- 色面の上に、さらに色面を重ねない。
- 章扉は、画像ではなく活字で作る（大きな章番号＋章題）。

## 5. 主役と山場

構造が分かりやすいだけでは、読み手は読みたくならない。作る前に、次を決める。

1. **世界観は、色と活字だけで作る。** 題材から色の気分を導く（例：川崎の臨海の夜＝深い紺）。
2. **1頁に主役は1つ。他の要素の3倍以上の大きさにする。** 主役は活字（巨大な数字や短い言葉）。KF R9の例：「R9」185pt、「法人格がない」89pt、「共催／主催」89pt、「ご了承を、」107pt。
3. **図は、単純な形で語る**：路線図（番号付きの駅）、原因から答えへの1本の矢印、2つの対比。
4. **数値を、図形の大小・高さで暗示しない**（上り階段、傾く点線、棒の高さで見せない）。目標値には、同じ行に「（目標）」を付ける。数字の単位や範囲のラベルを、数字に比べて小さくしすぎない（範囲のラベルは同じ行に25pt以上）。
5. **画像は作らない。** 型B・C・Dでは、表紙・扉も色面と活字で作る。生成画像は質が上がらず、安っぽく見え、読みやすさ・印刷・手直しのしやすさも落とす。使うのは、依頼者が質の高い素材（実写など）を渡したときだけ。

## 6. 定型の部品

**期限札**（印判のように）：朱の塗りに、内側0.05インチの細い枠線を1本（字と同じ色、透明度55%）。同じ語（例「12月中旬まで」）は、全頁で同じ言い方・同じ色・30pt・同じ大きさ（幅3.1×高さ0.74インチ）にする。幅が3.0インチ未満だと「12月中旬ま／で」と折り返す。`lib.js` の `plate`。

**確定／未確定の札**：塗り＋実線＝確定、白地＋破線＝未確定。`lib.js` の `tag`。

**数字と単位**：別々の箱に置き、下端をそろえる（和欧のすき間を避ける）。`lib.js` の `numline`。

**路線図**（誰が・いつ・何をする流れ）：主体ごとの横線（レーン）の上に、番号付きの駅を左から右へ並べ、駅の間を太い線（2.5pt）でつなぐ。関門の駅だけ朱で塗る（番号は白）。ラベルは駅の上か下に置き、線に触れさせない。段階の見出し帯は横に並べ、最後の段階（支払など）だけ夜色にする。部品はないので、`box`・`badge`・`arrow` で組む。

**折り返し**：描画環境で幅が違うため、日本語の長めの文は `\n` で句の切れ目に改行を入れる。1行は全角13字前後（17pt、幅3.8インチの列）まで。1字だけの折り返しを残さない。

## 7. 使わないもの（レビューで指摘された失敗）

円の中のアイコン／縦書き（LibreOfficeで後続の文字に重なる）／黄・琥珀／警告色の平塗りの箱／値を暗示する図形／画像（表紙・扉を含む）／文字の背後の飾りの帯／影・図形のグラデーション／絵文字／太字の連発／尺度外の文字サイズ／185ptを超える文字／彩度の高い朱／太い枠線。

既存の資料を改版するときは、頁番号の振り直しと、項目の順の入れ替えをしない（読み手が前の版と照らし合わせるため）。

## 8. 重要案件の検証の進め方

Agentツールが使え、依頼者が求めた場合に行う。

1. 方向を3つ決め、別々のエージェントに試作させる：A エディトリアル（活字が主役）／B 図解（路線図）／C 配色と余白の世界観。各エージェントは、自己点検して3〜5回磨く。
2. 別のレビュー3役（読み手・視覚・事実）が、6軸で採点する：①1秒の印象 ②独自性 ③階層・活字 ④図の力 ⑤統一とリズム ⑥実装性・印刷。頁ごとの勝者と、融合案も出させる。
3. 融合版を1つ作り、全頁を描画して目視し、`audit.py` を通す。
4. 別の種類のエージェントを使うときは、同じ指示書（特定のエージェントに依存しない書き方）を渡し、方向D（自由）として加える。作品は同じ6軸で比べる。
