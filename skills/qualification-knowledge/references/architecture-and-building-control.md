# 一級建築士／建築基準適合判定資格者

条番号・数値・施行日は覚え書き。使う前に、e-Gov法令検索と国土交通省の公表資料で確認する。

## A. 一級建築士

### 責任と名称（建築士法）

| 事項 | 要点 |
|---|---|
| 独占業務 | 一定の建築物の設計・工事監理は、建築士でなければできない（規模・構造により、一級・二級・木造の別） |
| 職責 | 業務に必要な知識・技能の維持向上、公正かつ誠実な業務 |
| 設計の原則 | 法令・条例の基準に適合させる。設計の内容を、委託者に適切に説明する。設計図書への記名 |
| 工事監理 | 工事が設計図書どおりでないと認めたときは、施工者に指摘し、従わなければ建築主に報告。終了時に、建築主へ文書で報告 |
| 報酬を得て業として行う場合 | 建築士事務所の登録が要る。管理建築士の配置、重要事項の説明、書面による契約（一定規模以上）、帳簿・図書の保存 |
| 定期講習 | 建築士事務所に所属する建築士は、一定期間ごとに受講（事務所に所属しない場合の扱いは条文で確認） |
| 構造設計・設備設計一級建築士 | 一定規模以上の建築物で、関与が義務付けられる |
| 業務報酬基準 | 国土交通省告示による略算方法。令和6年に新しい告示へ改められた（告示番号・内容は原文で確認） |
| 懲戒 | 戒告、業務停止、免許取消し。処分は公表される |

公務員が職務として設計・監理を行う場合と、個人として業を行う場合では、事務所登録・兼業許可の扱いが違う。後者は必ず確認する。

### 知識の地図（学科の5分野）

| 分野 | 主な内容 | 更新すべき論点 |
|---|---|---|
| 計画 | 建築計画、建築史、都市計画、積算、マネジメント | 木造・木質化の中大規模化、既存ストックの活用、BIM・建築確認のBIM図面審査、発注方式の多様化（DB、ECI、CM） |
| 環境・設備 | 熱・光・音・空気、空調・給排水・電気・防災設備 | 省エネ基準の適合義務の拡大（令和7年4月）、ZEB・ZEH、建築物のライフサイクルカーボン、再エネ設備の設置促進、表示制度 |
| 法規 | 建築基準法、建築士法、都市計画法、消防法、バリアフリー法、関係法令 | 確認の対象の見直し（4号特例の縮小。令和7年4月）、防耐火規制の合理化（木造）、既存建築物の増改築・用途変更の緩和、建築副主事と適合判定資格者の区分（令和6年4月）、盛土規制法 |
| 構造 | 構造力学、各種構造、荷重・外力、耐震設計、地盤・基礎、材料 | 木造の壁量・柱の小径の基準の見直し（令和7年4月）、長周期地震動、非構造部材・天井、既存建築物の耐震診断・改修、CLT等の木質材料 |
| 施工 | 施工計画、各種工事、品質・安全・工程管理、契約 | 働き方改革（時間外労働の上限規制の適用）、建設業法の改正（適正な工期、価格転嫁、労務費の基準）、建設キャリアアップシステム、スライド条項、ICT施工 |

### 一級建築士の所見で落としやすい点

- 既存建物：検査済証、増改築の履歴、石綿（事前調査と報告の義務）、PCB、耐震診断の有無。
- コスト：概算の時点と根拠（単価の出典、物価の変動）。近年の工事費上昇を織り込んだか。
- 維持管理：ライフサイクルコスト、修繕周期、運用時のエネルギー。
- 安全：避難、防火区画、落下物、工事中の第三者災害。
- 法規と性能は別：法適合は最低基準であり、発注者の求める性能（BCP、快適性、環境）とは別に示す。

## B. 建築基準適合判定資格者

### 制度（建築基準法）

| 事項 | 要点 |
|---|---|
| 資格 | 建築基準適合判定資格者検定に合格し、国土交通大臣の登録を受けた者。令和6年4月から、一級と二級の区分がある |
| 建築主事・建築副主事 | 自治体が、登録を受けた職員の中から命じる。建築副主事は、一定の小規模な建築物の確認等を担う（令和6年4月新設） |
| 確認検査員 | 指定確認検査機関で確認検査を行う者。登録を受けた者から選任 |
| 特定行政庁 | 建築主事を置く市町村の長、その他は都道府県知事。許可・認定・違反是正命令の主体（確認は建築主事等の権限であり、主体が違う） |
| 審査の範囲 | 建築基準関係規定への適合。計画が規定に適合するかを審査するもので、裁量の余地は狭い |
| 審査の指針 | 確認審査等に関する指針（国土交通省告示）。審査・検査の方法と、図書の不備への対応 |
| 構造計算適合性判定 | 一定の構造計算を行った建築物は、適合性判定が要る。判定を行う資格（構造計算適合判定資格者）は別 |
| 省エネ適合性判定 | 建築物省エネ法による。確認と連動（適合判定通知書がなければ確認済証が出ない） |
| 期間 | 確認の法定期間、中間検査・完了検査の申請と実施の期限 |
| 不服申立て | 建築審査会への審査請求。周辺住民からも起こりうる |

### 審査の視点の地図

| 区分 | 主な規定 |
|---|---|
| 手続 | 確認の要否（新築・増改築・大規模の修繕と模様替・用途変更・工作物・昇降機）、計画変更、軽微な変更、仮使用認定 |
| 単体規定 | 構造耐力、防火・耐火、避難、内装制限、採光・換気、シックハウス、階段、設備、昇降機 |
| 集団規定 | 道路・接道、用途制限、容積率、建蔽率、高さ・斜線・日影、防火地域、地区計画条例、建築協定 |
| 建築基準関係規定 | 消防法、都市計画法（開発許可等）、屋外広告物法、港湾法、駐車場法、水道法、下水道法、宅地造成及び特定盛土等規制法、バリアフリー法、都市緑地法、建築物省エネ法 など（施行令で列挙。範囲は原文で確認） |
| 既存建築物 | 既存不適格の確認方法（既存不適格調書）、増改築・用途変更での遡及の範囲、検査済証のない建築物の扱い（国のガイドラインによる調査） |
| 許可・認定（特定行政庁） | 接道の特例、用途の特例許可、総合設計、一団地・連担、仮設建築物、一時的な用途変更 |

### 実務で価値が出る場面

- 公有施設の活用・用途変更の企画で、**確認の要否と、遡及して直す範囲**を早期に見立てる。
- 民間提案・社会実験で、仮設建築物・一時的用途変更・工作物の扱いを整理する。
- 判例に照らしたリスクの見立て（確認の留保、指定確認検査機関の確認と自治体の責任、周辺住民の争い方）。`japan-law-research` の `references/key-precedents.md`。
- 職務上の判断権限は、任命されている者にある。資格を持つことと、当該案件の判断権限を持つことを混同しない。

## C. 確認に使う一次情報

- 国土交通省：建築基準法・建築士法の改正概要、技術的助言、告示、質疑応答集、既存建築物の活用に関するガイドライン。
- 日本建築行政会議：建築確認のための基準総則・集団規定の適用事例、建築設備設計・施工上の運用指針（刊行物。実務の標準的な解釈）。
- 建築技術教育普及センター：建築士試験・適合判定資格者検定の案内と過去の問題。
- 日本建築学会の基準・指針・標準仕様書（JASS）、公共建築工事標準仕様書（国土交通省）。
- 所属する特定行政庁の取扱基準・条例。
