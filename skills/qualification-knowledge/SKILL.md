# 保有資格の知識補完

対象ユーザーの資格：**一級建築士／技術士（建設部門：都市及び地方計画）／建築基準適合判定資格者／データサイエンティスト**。資格取得時の知識は、法改正と技術の進歩で古くなる。このスキルは、①現行制度への更新、②専門家としての所見の質の担保、③資格の責任範囲の確認、の3つを支える。

## 最初にやること

| モード | 典型的な依頼 | 読む参照ファイル |
|---|---|---|
| A 専門家としての所見を書く | 「建築士として」「技術士の視点で」「確認審査の観点では」 | 該当資格の節 |
| B 知識を更新する | 「最近の改正は」「〇〇を学び直したい」 | 該当資格の「更新すべき論点」 |
| C 資格の使い方を確認する | 「名刺・提案書にどう書くか」「この業務は資格の範囲か」「講習・CPDは」 | 「責任と名称」の節 |
| D 学習計画を作る | 「弱い分野を補いたい」「試験・更新に備えたい」 | 下の「学び直しの手順」 |

参照ファイル：`references/architecture-and-building-control.md`（一級建築士・建築基準適合判定資格者）、`references/pe-and-data-science.md`（技術士・データサイエンティスト）。

## 共通ルール

- 最初に「概略」を簡単な日本語で、次に詳細を書く。
- **制度・条文・数値は、現行のものを一次情報で確認してから書く**（`japan-law-research` の手順）。参照ファイルは論点の索引であり、古くなる。確認できないものは「要確認」と書く。
- 所見は「事実 → 適用する基準 → 判断 → 留保」の順に書く。資格者の所見は、根拠が示されて初めて価値がある。
- **公務員としての立場と、資格者個人としての立場を分ける。** 職務上の見解か、個人の専門的意見かを明示する。職務外で資格を使う業務（設計、鑑定、コンサルティング）は、兼業の許可と利益相反の確認が先（地方公務員法38条。`startup-corporate-finance`）。
- 資格の独占業務に当たる行為（設計・工事監理、確認検査）について、資格を持たない者が行えるかのような助言をしない。

## モードA：専門家としての所見の型

```
1. 依頼の内容と、所見の前提（見た資料、現地確認の有無、時点）
2. 適用する基準（法令・告示・基準・指針。版と条番号）
3. 所見（基準ごとに、適合／不適合／判断できない）
4. 判断できない点と、その理由（資料不足、現地未確認、解釈が分かれる）
5. 推奨する対応（追加調査、所管への協議、専門家への依頼）
6. 所見の性格（職務上／個人の専門的意見。法的な確認・証明ではないこと）
```

複数の資格の視点を重ねると、所見に厚みが出る：

| 論点の例 | 建築士の視点 | 適合判定資格者の視点 | 技術士（都市計画）の視点 | データの視点 |
|---|---|---|---|---|
| 廃校の活用 | 改修の設計・コスト・耐震 | 用途変更の確認、既存不適格、検査済証 | 地域の公共施設再編、立地の適正 | 利用需要の推計、到達圏 |
| 駅前の再開発 | 建物の計画、工事費 | 集団規定、緩和の適用関係 | 都市計画の整合、交通、合意形成 | 人流・地価への効果検証 |
| 公園の民間活用 | 施設の設計、建蔽率の特例 | 公園施設の建築確認、仮設 | 公園経営、地域との関係 | 利用者数、満足度の測定 |
| 木造密集地域 | 耐震・防火改修 | 接道、連担建築物設計制度 | 防災街区、避難、権利調整 | 延焼シミュレーション、優先順位付け |

## モードB：知識の更新

1. 対象分野を決める（法規／構造／設備・環境／施工／計画、都市計画の各論、統計・機械学習）。
2. 参照ファイルの「更新すべき論点」から、該当項目を選ぶ。
3. **所管省庁・試験機関・学協会の一次情報で、現行の内容を確認する。** 改正の施行日、経過措置、実務への影響を表にする。
4. 「以前の理解 → 現在の内容 → 実務で変わること」の3列で示す。
5. 確認問題を3問付ける（理解の定着のため。求められた場合）。

## モードC：資格の責任と名称

- 資格ごとの義務・講習・名称の使い方は、参照ファイルの「責任と名称」にまとめてある。期限のある義務（定期講習など）は、根拠条文と自分の受講履歴で確認する。
- 提案書・名刺・記事での表記は、正式名称と登録部門を書く。資格で保証できる範囲を超える表現（「建築士が安全を保証」など）は避ける。

## モードD：学び直しの手順

1. 棚卸し：分野ごとに「説明できる／調べれば分かる／分からない」を自己評価する。
2. 優先順位：実務で使う頻度 × 誤ったときの影響、で決める。
3. 教材は一次情報を軸にする（法令、告示、国の技術基準、学会の基準・指針、試験機関の公表資料）。解説書は補助。
4. 週あたりの時間を決め、4週間の計画にする。週1回、自分の言葉で要点を書く（noteの記事にすると、発信と学習を兼ねられる）。
5. 3か月後に同じ棚卸しをして、変化を見る。
