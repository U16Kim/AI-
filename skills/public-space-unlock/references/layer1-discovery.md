## 2. 低利用スコアの設計

単一指標で決めない。最低3系統を合成する。

### 指標の候補

**A. 利用実態系（最も直接的。入手できれば最優先）**
- 稼働率（公表されていれば）
- 年間利用者数 ÷ 定員 or 面積
- 開館日数

**B. 立地ポテンシャル系（低利用でも価値が高い場所を拾う）**
- 駅・バス停からの距離
- 徒歩圏人口（小地域集計から算出）
- 周辺の同種施設密度（近すぎると競合、遠すぎると需要が薄い）

**C. 物理条件系（使えるかどうか）**
- 建築年（用途変更のしやすさに直結）
- 延床面積
- 敷地面積、接道状況

### 合成の考え方
「低利用 × 立地ポテンシャル高」が最も価値のある候補になる。
単に低利用なだけの遠隔地の施設を上位に出しても、担い手は使えない。

推奨：各指標を偏差値化またはmin-max正規化し、
`スコア = w1×(低利用度) + w2×(立地ポテンシャル) + w3×(転用容易性)`
の重み付き和とする。重みはユーザーと相談して決め、**必ず感度分析（重みを
±15%動かして順位が変わるか）を行う**こと。

## 3. 実装

### 環境
Anaconda/JupyterLab と Google Colab の両対応で書く。
Colabの場合は冒頭に `!pip install geopandas folium` を付す。

### 基本パターン

```python
# 誰が：分析者（木村さん）が
# どのアプリで：JupyterLab または Google Colab で
# 何を：公有施設データと小地域人口データを
# どうする：結合し、低利用スコアを算出してランキングする

import pandas as pd
import geopandas as gpd
import numpy as np

# --- 1. 施設データの読み込み ---
# 自治体オープンデータのCSV（施設名・緯度・経度・延床面積・建築年など）
fac = pd.read_csv("facilities.csv", encoding="utf-8")
gdf_fac = gpd.GeoDataFrame(
    fac,
    geometry=gpd.points_from_xy(fac["経度"], fac["緯度"]),
    crs="EPSG:4326"
)

# --- 2. 距離計算のため投影座標系へ変換 ---
# 関東であれば平面直角座標系9系（EPSG:6677）を使う
# 緯度経度のまま距離を測ると誤差が出るため必須の手順
gdf_fac = gdf_fac.to_crs("EPSG:6677")

# --- 3. 駅データを読み込み、最寄り駅までの距離を算出 ---
gdf_sta = gpd.read_file("station.shp").to_crs("EPSG:6677")
joined = gpd.sjoin_nearest(
    gdf_fac, gdf_sta[["geometry"]],
    how="left", distance_col="dist_station_m"
)

# --- 4. 各指標を0-1に正規化 ---
def minmax(s, reverse=False):
    """0-1に正規化。reverse=Trueで小さい値ほど高スコアにする"""
    s = pd.to_numeric(s, errors="coerce")
    out = (s - s.min()) / (s.max() - s.min())
    return 1 - out if reverse else out

joined["s_lowuse"]    = minmax(joined["稼働率"], reverse=True)   # 稼働率が低いほど高得点
joined["s_access"]    = minmax(joined["dist_station_m"], reverse=True)  # 駅に近いほど高得点
joined["s_convert"]   = minmax(joined["建築年"])                  # 新しいほど転用しやすい

# --- 5. 重み付き合成 ---
W = {"s_lowuse": 0.5, "s_access": 0.3, "s_convert": 0.2}
joined["score"] = sum(joined[k] * w for k, w in W.items())

ranking = joined.sort_values("score", ascending=False)
print(ranking[["施設名", "score", "稼働率", "dist_station_m", "建築年"]].head(20))
```

**コードの解説（必ずユーザーに説明すること）：**
- `to_crs("EPSG:6677")` は、地球の丸みを考慮した座標に変換する処理。
  緯度経度のまま距離を計算すると誤差が出るため、距離を測る前に必ず行う。
  関東は9系（6677）、関西は6系（6674）など地域で番号が変わる。
- `sjoin_nearest` は、各施設に最も近い駅を空間的に探して結びつける処理。
- `minmax` は、単位の違う指標（％、メートル、年）を同じ0〜1の物差しに
  揃えるための処理。これをしないと、桁の大きい指標だけが結果を支配してしまう。

### 感度分析（必須）

```python
# 重みを±15%動かして、上位10件の顔ぶれが変わるかを確認する
base_top = set(ranking.head(10)["施設名"])
for k in W:
    for d in (0.85, 1.15):
        W2 = dict(W); W2[k] = W[k] * d
        s = sum(joined[c] * w for c, w in W2.items())
        top = set(joined.assign(sc=s).sort_values("sc", ascending=False).head(10)["施設名"])
        print(f"{k} x{d}: 上位10件のうち {len(base_top & top)} 件が一致")
```

一致が7件を下回る指標があれば、その重みの設定が結果を左右しすぎている。
ユーザーに提示して重みを再検討する。

### QGIS でのクリックフロー（地図化する場合）
1. `レイヤ` → `レイヤを追加` → `デリミテッドテキストレイヤを追加`
2. CSVを選択し、X属性に「経度」、Y属性に「緯度」、ジオメトリのCRSに `EPSG:4326` を指定 → `追加`
3. レイヤを右クリック → `エクスポート` → `新規ファイルに地物を保存` → CRSを `EPSG:6677` に変更して保存
4. レイヤのプロパティ → `シンボロジー` → `等級に分けられた` → 値に `score`、モードに `自然分類（Jenks）` → `分類`
5. `プロジェクト` → `新規印刷レイアウト` で地図を書き出す
