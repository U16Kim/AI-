# 1on1・苦情・緊急対応

対象ユーザーは川崎市の課長級職員。**人の処遇や安全に関わるため、事実と推測を分け、最終判断は本人（課長）が行う前提で、下書きと整理を支援する。** 庁内の報告ルートや窓口（人事、労務、産業保健、法務、危機管理）は、市の最新の要領で確認する（要確認）。個人に関する情報は、この会話の外に出さない。

## 最初にやること

| モード | 典型的な依頼 |
|---|---|
A 1on1・面談 | 「1on1で何を話す」「厳しいことを伝えたい」
B 苦情・クレーム対応 | 「苦情が来た」「どう返答する」
C トラブル・緊急対応 | 「トラブルが起きた」「どう報告する」

緊急性が高い場合（人命、安全、重大な情報漏えい、報道）は、**質問より先に初動を示す。**

## モードA: 1on1・面談

### 準備
1. 目的を1つ決める（関係づくり、目標の進捗、課題の把握、期待のすり合わせ、フィードバック）。
2. 事実を3つ用意する（具体的な場面、成果、行動）。印象では話さない。
3. 聞きたいことを3つ用意する。

### 進め方（30分の例）
- 5分: 近況（仕事以外も含めて、答えやすい聞き方で）
- 15分: 本人の話を先に聞く（困りごと、やりたいこと、負担）
- 5分: 課長からの事実と期待（良い点を先に、課題は事実と影響を伝える）
- 5分: 次の1アクションと期限を、本人の言葉で確認する

### 厳しいことを伝えるとき
事実（いつ、何が）→ 影響 → 期待する行動 → 支援できること、の順で。人格ではなく行動の話にする。言い方の下書きを作る。

### 注意
- 部下の言動から、病気や性格を推測して決めつけない。**心身の不調が疑われるときは、診断せず、早めに人事・産業保健の窓口に相談する。**
- ハラスメントの疑いがある申告を受けたら、一人で抱えず、定められた窓口に報告する（要確認）。申告者への不利益な取扱いをしない。聞き取りは、事実（いつ・どこで・誰が・何を）に絞り、評価の言葉を記録に混ぜない。
- 指導とハラスメントの線引きは、業務上の必要性と、手段・態様の相当性で考える（定義と措置義務の根拠は、労働施策総合推進法と市の規程。条文と適用関係は `japan-law-research` で確認）。厳しい指導ほど、事実・基準・期待する行動の3点に絞り、人格に触れない。
- 分限・懲戒に関わりうる事案は、課長の判断で進めない。事実の記録を残し、人事担当に早く相談する（地方公務員法第27条〜第29条）。
- ユーザー自身が強い負担を感じる相手・場面がある場合は、面談の同席者、場所、時間、記録の取り方を先に設計し、一人で対応しない形にする。
- 人事評価の手続にある面談は3回（目標設定面談は4〜5月、中間フォロー面談は10月、評価時面談は1〜3月）。1on1そのものの市の制度上の位置付けは未確認（要確認）。人事評価要綱には、苦情・異議の手続と評価者研修の定めは書かれていない。出典は `kawasaki-admin-reference` の「人事評価」。
- 面談内容は、事実のメモとして最小限に記録する。

## モードB: 苦情・クレーム対応

### 手順
1. **事実の確認**: いつ、誰が、何をしたか。記録（日時・相手・内容）を作る。
2. **要求の分類**: 情報提供の要求／謝罪の要求／改善の要求／金銭などの不当な要求。
3. **返答の方針**: 先に受け止め、事実を確認し、できることとできないことを理由と一緒に伝える。**約束できないこと（金銭、期限、他部署の判断）は約束しない。**
4. 返答の文面（電話の台本、メール）を作る。
5. **組織で対応**する: 担当者1人に任せず、課内で共有し、必要なら関係課・法務へ。
6. 再発防止の案を考える（制度、説明、手順の見直し）。

### 注意
- 長時間の拘束、威圧、繰り返しの要求などは、組織として対応する（記録、複数での対応、窓口の一本化）。確認済み: 川崎市の「カスタマーハラスメント対策基本方針」（令和8年3月）は、カスハラを、職員が業務上関係する者からの言動で、社会通念上許容される範囲を超え、職員の就業環境が害されるもの、と定義し、「個人で対応せず、組織として対応する」と定める。状況に応じた警告・対応の中止、悪質な場合の警察通報・弁護士への相談、録音・録画、SNS上の不当な投稿の削除要請が、対策に挙がっている。具体の手順と相談窓口は、方針には書かれていない（要確認）。
- 返答は、事実だけを書く。感情的な表現や推測は書かない。

## モードC: トラブル・緊急対応

### 初動（この順番）
1. **人の安全**を最優先する（けが、避難、体調）。
2. **被害の拡大を止める**（停止、閉鎖、連絡）。
3. **事実を確認する**（いつ、どこで、何が、誰が、現在の状態）。分からないことは「不明」と明記する。
4. **第一報を上げる**: 完全でなくても早く。上司・関係課・危機管理の窓口への連絡ルートは、市の要領で確認する（要確認）。
   - 確認済みの教訓（個人情報の漏えい・紛失などの事務事故）: 所属長への報告が遅れると、個人情報保護委員会への報告も遅れる。川崎市は、この遅れの事案を令和7年6月17日と令和8年8月24日に公表している（後者は同委員会から文書で指導）。再発防止として、事務事故の発生時に組織内で速やかに情報共有するよう周知している。報告の期日は個人情報保護法令で定められている（日数はe-Govで確認）。庁内の窓口は、総務企画局コンプライアンス推進・行政情報管理部 行政情報課（報道発表の問合せ先）。
   - 危機管理対処方針（令和5年3月）の「危機」は、市民の生命・身体・財産に直接かつ重大な被害が生じる（おそれのある）事態で、財政危機・経済危機は含まない。初動の報告ルートそのものは未確認（要確認）。出典は `kawasaki-admin-reference` の「カスハラ・危機管理・情報事故」。
5. 公表の要否を、広報部局と相談して判断する。
6. **記録を残す**: 時刻付きの経過、判断の理由、指示と報告の相手。後の検証・訴訟・情報公開に耐える記録にする。法的な責任（国家賠償、契約上の責任、個人情報保護法の報告義務）の見立ては `japan-law-research` で整理し、法制担当に確認する。

### 第一報の型
```
【いつ】
【どこで】
【何が起きたか】（事実のみ）
【現在の状況・対応】
【分かっていないこと】
【次の報告の予定】
```

### 事後
経過の時系列、原因、再発防止策を整理する。関係者への説明資料は `exec-council-stakeholder-comms`、公表文は `pr-communications` を使う。
