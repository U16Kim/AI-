# 東京都・横浜市の制度と実務／3都市比較（確認日 2026-11-15）

川崎市の課長が、隣接する2自治体の制度を調べ、比べるための参照集と手順。**確認できた事実は少ない。** このスキルの中心は「どこを、どう調べ、どう比べるか」であり、事実は使う前に公式サイトで確かめ直す。

## 使い方と注意

- 凡例：◎＝公式資料の本文で確認／○＝公式サイトの検索結果の要旨で確認（原文の再確認が必要）／構造＝法律上のしくみに基づく整理（条文で確認）
- 今回の確認は、公式サイトを対象にしたウェブ検索の結果による（2026-11-15）。**○の事項は、文書に引用する前に必ず原文を開く。**
- 組織名・所管は毎年度変わる。古い資料の組織名をそのまま書かない。
- ここに無い事項は「未確認」。末尾の未確認リストを見て、推測で埋めない。
- 人口・予算規模などの数値は載せていない（時点で変わるため）。使うときは、各団体の統計ページと予算概要で最新値を取り、時点を書く。

## 1. 3都市の制度上の違い（構造）

| 観点 | 東京都 | 横浜市 | 川崎市 |
|---|---|---|---|
| 団体の種類 | 都（広域の団体）。23区は特別区（基礎的な団体） | 政令指定都市 | 政令指定都市 |
| 根拠 | 地方自治法281条〜（都区制度） | 同法252条の19 | 同左 |
| 区の性格 | 特別区は法人格を持ち、区長・区議会を選挙で選ぶ | 行政区（市の内部組織。区長は市長が任命） | 同左 |
| 都市計画の決定 | 特別区の区域では、用途地域など一般の市が決める都市計画の一部を都が決める（都市計画法の都の特例。対象は条文で確認） | 指定都市の特例により、県決定の多くを市が決める（都市計画法87条の2） | 同左 |
| 建築行政 | 都と特別区・市が、規模等で分担して特定行政庁となる | 市が特定行政庁 | 同左 |
| 税財政 | 特別区の区域では、固定資産税・市町村民税法人分等を都が課し、都区財政調整で配分 | 市が課税。県費負担との関係は事務ごと | 同左 |
| 道府県との関係 | 都自身が広域団体 | 神奈川県の区域内。県の事務の一部を処理 | 同左 |

**比較の落とし穴**：東京都の制度は、広域団体としての制度（市町村への補助、広域計画）と、特別区の区域で基礎的団体の役割を担う制度が混ざっている。川崎市と比べる相手は、事項によって「都」「特別区」「多摩の市」のどれかに変わる。先に「どの層と比べるか」を決める。

## 4. 3都市比較の作り方

1. **比べる目的を決める**（制度の新設・見直し／議会対応／幹部説明）。目的で、必要な深さが変わる。
2. **比べる層を決める**（1の「比較の落とし穴」）。
3. **比較軸を決める**：根拠（条例・規則・要綱）／所管／対象／内容・水準／手続／実績／評価・課題／開始時期と見直しの経緯。
4. **一次情報で埋める**：例規集 → 所管課のページ → 予算・事業評価 → 議会会議録の順。各セルに出典URLと確認日を付ける。
5. **そろえて比べる**：金額は人口や予算規模あたりに直す。年度をそろえる。制度の名前ではなく、実際の運用（件数、執行率）を見る。
6. **違いの理由を説明する**：制度上の地位（1の表）、財政力、産業構造、地理、歴史。理由のない差だけが、川崎市への示唆になる。
7. **示唆を出す**：採用する／修正して採用する／採用しない、と理由。
8. 埋まらなかったセルは「確認できず」と書く。

```
| 比較軸 | 川崎市 | 横浜市 | 東京都（層：都／特別区／市） | 出典・確認日 |
|---|---|---|---|---|
```

事例の調査手順は `rules-research-and-subsidy-drafting` のモードB、資料化は `logic-storyline` と `kmr-visual-deliverables` を使う。

- 新しく確認できた事実は、該当の表に「内容・確認の印・URL」を1行で足し、冒頭の確認日を更新する。
- 確認から3か月を過ぎた事項、年度をまたいだ事項は、使う前に再確認する。
