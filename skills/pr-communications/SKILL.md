# 広報・情報発信

対象ユーザーは川崎市の課長級職員。共創推進室は、官民連携事業の創出と、その発信が主業務。**伝える中身は事実に基づき、数値と固有名詞は確認できたものだけを書く。** 市のルール（広報の手続、SNS運用、記者への提供方法、市長・幹部への事前説明の要否）は、市の最新の要領で確認する（要確認）。

## 最初にやること

| モード | 典型的な依頼 |
|---|---|
A 報道発表資料 | 「プレスリリースを書いて」
B 事例・記事・SNS | 「官民共創の事例を発信したい」「Web記事にして」
C 取材・記者対応 | 「記者に聞かれたらどう答える」「取材の準備」

不足情報は、まとめて1回だけ質問する（最大3項目）。

## 共通ルール

- 最初に「概略」を簡単な日本語で、次に詳細を書く。
- 一文目で、誰が何をするかが分かること。専門用語は使わない、使うなら説明する。
- 数値には出典と時点を付ける。誇張しない（「日本初」「最大」は根拠が確認できたときだけ）。
- 民間企業名・商品名・ロゴを使う場合は、**相手方の事前確認**と、**他の事業者との公平性**（特定企業の宣伝に見えないか）を確認する。
- 個人情報・写真の掲載は、同意と目的を確認する。
- 伝える順と見出しは `logic-storyline` で設計する（一文目の結論、最も効く数字1つ、当事者の具体的な場面）。資料のデザインと、HTML・PPTX・PDFにする場合の基準は `kmr-visual-deliverables` に従う。
- 表示・権利の確認: 効果・実績の表現（根拠のない優良誤認を避ける）、写真・図・文章・音楽の著作権と利用条件、肖像の同意、生成AIで作った画像・文章の扱い。迷う点は `japan-law-research` で根拠を確認する。
- 作成後は `deliverable-verifier` で事実と数値を検証する。

## モードA: 報道発表資料

### 構成（この順で書く）
1. **見出し**: 15〜30字程度で、新しさと主語が分かるもの。
2. **リード文**: いつ・どこで・誰が・何を・なぜ（5W1H）を3文以内で。
3. **背景と目的**: 課題を数値で1〜2文。
4. **内容の詳細**: 日時、場所、参加方法、費用、申込方法。
5. **関係者のコメント**（必要な場合、本人の確認後）。
6. **今後の予定**。
7. **問い合わせ先**。
8. **写真・図の候補と、掲載の可否**。

### 手順
1. ニュースとしての価値を、1文で言う（なぜ今、誰にとって新しいのか）。
2. 上の構成で下書きを書く。
3. 関係者・関係課の確認が要る箇所を一覧にする。
4. 公表日・時刻、解禁の扱い、提供先は、市の広報要領で確認する。確認済み: 「報道発表資料のホームページ掲載に関する要綱」がある（ファイル名から令和4年6月1日付と読めるが、原文で確認）。過去の発表は、市の月別報道発表ページで書式の実例を見られる（URLは `kawasaki-admin-reference` の「広報・発信」）。事前提供のルールと承認ルートは未確認（要確認）。
5. 想定問答（取材で聞かれること5つ）を付ける。

## モードB: 事例・記事・SNS

### 手順
1. 誰に、何をしてほしいか（参加、応募、理解、協力）を決める。
2. 事例記事の型: **課題 → きっかけ → 官民の役割 → 工夫 → 成果（数値） → 今後**。
3. 成果は、可能な限り前後比較か指標で示す。確認できない効果は書かない。
4. 媒体ごとに書き分ける（Web記事は詳しく、SNSは1メッセージ、イベント告知は日時と行動を先頭に）。
   - 市の公式SNSの確認済みルール（「ソーシャルメディアの利用に関するガイドライン」）: アカウント名は原則「川崎市○○○」、アカウント情報は組織名（個人名・役職名は不可）、登録メールは組織のアドレス、媒体ごとに「アカウント運用ポリシー」を策定して市ホームページで公表、利用の開始・廃止は報告。報告先は旧組織名（シティプロモーション推進室）で書かれているため、現在の担当は要確認。ガイドライン自体が最新版かも要確認。
5. 国内外の類似の発信事例を1〜2件挙げ、自分たちの発信の差別化点を示す。
6. 民間企業の掲載は、公平性の説明（選定の過程、他社にも同様の機会があること）を用意する。
   - 官民連携の事例は、官民連携総合窓口（Kawasaki Future Co‑Lab）のテーマ型・フリー型提案という入口があることを、公平性の説明に使える。
   - 広告・協賛・後援は、別の手続になる。広告は「川崎市広告掲載要綱」（平成17年）と広告掲載基準、協賛の実例はかわさきTEKTEK（協賛品の総額の定価でランクが決まり、体験型協賛は金額に換算して申請）、後援名義等は局ごとの要綱（実例: 経済労働局）がある。共創推進室の後援名義等の取扱いは未確認（要確認）。URLは `kawasaki-admin-reference` の「広報・発信」。

## モードC: 取材・記者対応

### 手順
1. 取材の目的と、聞かれそうなこと（好意的／批判的）を整理する。
2. **伝えたいことを3点**に絞る。
3. 想定問答を作る。分からないことは「確認して後ほど回答する」と答える準備をする。
4. 公表できない情報（入札前の価格、個人情報、調整中の案件）を線引きする。
5. 取材の窓口と、回答の承認ルートを確認する（要確認）。
